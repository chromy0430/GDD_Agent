## 1. 시스템 개요

### 1.1 기획 의도

> **💭 왜 이 시스템을 만드는가?**
>
> **한국 전통 오행 사상**을 게임 메커니즘으로 구현하여 **문화적 정체성**과 **전략적 깊이**를 동시에 달성합니다.
>
> **핵심 목표**:
> - 🎭 **문화적 차별화**: 서양 4원소(불/물/흙/바람) 대신 동양 오행(화수목금토) 사용
> - ⚔️ **명확한 상성**: 1.5배/0.5배의 큰 배율로 속성 선택의 중요성 강조
> - 🧩 **전략적 다양성**: 5속성 순환 구조로 단순 암기가 아닌 이해 기반 전략
> - 🎯 **파티 시너지**: 같은 속성 4명 시 +30% 보너스로 특화 파티 육성 유도
>
> **차별화 포인트**:
> - 일반 RPG: 4원소 직선 상성 → **본 시스템**: 오행 순환 구조 (화→금→목→토→수→화)
> - 단순 데미지: 속성만 영향 → **본 시스템**: 스탯 보정 + 상태이상 + 시너지 통합
> - 획일적 전략: 무속성 만능 → **본 시스템**: 무속성 없음, 모든 전투에서 속성 고려 필수
>
> **한국 문화 요소 접목**:
> ```
> 화(火): 불꽃 - 도깨비의 불방망이, 열정과 파괴
> 수(水): 물 - 물귀신의 냉기, 생명과 치유
> 목(木): 나무 - 산신령의 생명력, 성장과 독
> 금(金): 번개 - 뇌신의 천벌, 속도와 심판
> 토(土): 대지 - 산신의 단단함, 방어와 인내
> ```
>
> **전략적 설계**:
> - 균형형 파티(3~4속성): 초보자 친화, 모든 상황 대응
> - 특화형 파티(1~2속성): 고급 전략, 특정 던전 최적화
> - 카운터형 파티: 보스 공략 전용, 최대 효율

### 1.2 시스템 목적
- 전투의 전략적 깊이 제공
- 속성별 특색과 차별화
- 파티 편성의 중요성 강조
- 플레이어의 의사결정 요소 제공

### 1.3 핵심 컨셉
**"오행(五行) 기반 상성 구조로 전략적 선택 유도"**

## 2. 5속성 구조

### 2.1 속성 종류 및 특징

| 속성 | 한자 | 색상 | 아이콘 | 컨셉 | 특징 |
|------|------|------|--------|------|------|
| 화 | 火 | 빨강 | 불꽃 | 공격 | 높은 화력, 폭발적 데미지 |
| 수 | 水 | 파랑 | 물방울 | 지원 | 회복, 생존력, 지속력 |
| 목 | 木 | 초록 | 나뭇잎 | 지속 | 독, 출혈, 지속 데미지 |
| 금 | 金 | 노랑 | 번개 | 속도 | 빠른 공격, 크리티컬 |
| 토 | 土 | 갈색 | 바위 | 방어 | 높은 체력, 방어력 |

### 2.2 속성별 스탯 보정

**화속성 (火)**:
```
공격력: +20%
스킬 데미지: +15%
크리티컬 데미지: +10%

약점: 방어력 -10%
컨셉: 강력한 일격으로 적을 제압
```

**수속성 (水)**:
```
HP: +25%
회복 효과: +20%
상태 이상 저항: +15%

약점: 공격력 -5%
컨셉: 높은 생존력으로 장기전 유리
```

**목속성 (木)**:
```
지속 데미지: +30%
디버프 성공률: +10%
HP 회복/턴: +5%

약점: 폭발력 부족
컨셉: 지속 데미지로 적을 약화
```

**금속성 (金)**:
```
속도: +15%
크리티컬 확률: +10%
회피율: +5%

약점: HP -10%
컨셉: 빠른 공격으로 선제 타격
```

**토속성 (土)**:
```
방어력: +30%
피격 데미지 감소: +10%
HP: +15%

약점: 속도 -10%
컨셉: 단단한 방어로 버티기
```

## 3. 속성 상성 관계

### 3.1 상성 구조
```
        화(火)
       ↙   ↖
     금(金)   수(水)
      ↓   ×   ↓
     목(木)   토(土)
       ↘   ↙
        (순환)
```

**상성 관계 표**:
| 공격 속성 | 유리 (1.5배) | 보통 (1.0배) | 불리 (0.5배) |
|----------|-------------|-------------|-------------|
| 화(火) | 금(金) | 화, 목, 토 | 수(水) |
| 수(水) | 화(火) | 수, 금, 목 | 토(土) |
| 목(木) | 토(土) | 목, 수, 화 | 금(金) |
| 금(金) | 목(木) | 금, 토, 수 | 화(火) |
| 토(土) | 수(水) | 토, 화, 금 | 목(木) |

### 3.2 상성 이론적 배경

**화(火) → 금(金)**:
- 불은 금속을 녹인다
- 높은 열로 금속 무기를 무력화

**금(金) → 목(木)**:
- 금속 도구로 나무를 자른다
- 날카로운 공격으로 생명체 제압

**목(木) → 토(土)**:
- 나무 뿌리가 땅을 뚫고 자란다
- 생명력으로 대지를 극복

**토(土) → 수(水)**:
- 흙이 물을 흡수하고 막는다
- 방벽으로 물의 흐름 차단

**수(水) → 화(火)**:
- 물이 불을 끈다
- 냉기로 열기를 제압

### 3.3 데미지 계산

**기본 공식**:
```
최종 데미지 = 기본 데미지 × 속성 배율

속성 배율:
- 유리: 1.5배
- 보통: 1.0배
- 불리: 0.5배
```

**복합 계산 예시**:
```
화속성 캐릭터 (공격력 1000) → 금속성 요괴

1. 기본 데미지: 1000
2. 속성 배율: 1.5배 (유리)
3. 최종 데미지: 1,500

추가 보정:
- 3매치: ×1.0
- 스킬 사용: ×3.0
- 크리티컬: ×1.5
→ 1,500 × 1.0 × 3.0 × 1.5 = 6,750
```

## 4. 속성 전략

### 4.1 파티 편성 전략

**균형형 (추천)**:
```
5속성 중 3~4속성 배치
- 장점: 모든 상황 대응 가능
- 단점: 특화 효과 부족
- 추천: 초중급 플레이어
```

**특화형**:
```
같은 속성 3~4명 편성
- 장점: 속성 시너지 극대화 (+30% 데미지)
- 단점: 불리한 상성 만나면 취약
- 추천: 고급 플레이어, 특정 던전 공략
```

**카운터형**:
```
특정 적 상대용 맞춤 편성
- 유리 속성 집중 배치
- 보스 공략에 최적화
- 던전별 전용 파티 구성
```

### 4.2 속성별 추천 역할

**화속성**:
- 주 역할: 메인 딜러
- 서브 역할: 버스트 딜러
- 추천 직업: 검사, 도사

**수속성**:
- 주 역할: 힐러, 탱커
- 서브 역할: 서포터
- 추천 직업: 의원, 방패병

**목속성**:
- 주 역할: 디버퍼, 지속 딜러
- 서브 역할: 서포터
- 추천 직업: 부적사, 도사

**금속성**:
- 주 역할: 크리티컬 딜러
- 서브 역할: 속공형 딜러
- 추천 직업: 궁사, 검사

**토속성**:
- 주 역할: 탱커
- 서브 역할: 브루저 (딜탱)
- 추천 직업: 방패병, 검사

## 6. 속성 시너지

### 6.1 파티 시너지 보너스

**같은 속성 2명**:
```
해당 속성 데미지 +10%
같은 속성 조각 스킬 게이지 충전 +10%
```

**같은 속성 3명**:
```
해당 속성 데미지 +20%
같은 속성 조각 스킬 게이지 충전 +20%
속성 저항 +10%
```

**같은 속성 4명**:
```
해당 속성 데미지 +30%
같은 속성 조각 스킬 게이지 충전 +30%
속성 저항 +20%
특수 효과: 해당 속성 조각 출현 확률 +5%
```

### 6.2 복합 속성 시너지

**화 + 금 (폭발형)**:
```
크리티컬 데미지 +15%
스킬 쿨타임 -10%
```

**수 + 목 (생명형)**:
```
HP 회복 +20%
HP 재생/턴 +3%
```

**토 + 수 (방어형)**:
```
방어력 +25%
받는 데미지 -15%
```

## 7. 속성 상태 이상

### 7.1 속성별 고유 상태 이상

**화속성 - 화상**:
```
효과: 매 턴 최대 HP의 3% 데미지
지속: 3턴
부가: 받는 회복량 -30%
```

**수속성 - 빙결**:
```
효과: 이동 불가, 다음 턴 스킵
지속: 1턴
부가: 방어력 -20% (얼어서 약해짐)
```

**목속성 - 독**:
```
효과: 매 턴 최대 HP의 5% 데미지
지속: 5턴
부가: 턴마다 데미지 증가 (+1%)
```

**금속성 - 감전**:
```
효과: 행동 시 20% 확률로 실패
지속: 2턴
부가: 방어력 -15%
```

**토속성 - 석화**:
```
효과: 이동 및 공격 불가
지속: 2턴
부가: 받는 데미지 -50% (돌로 변해 방어 상승)
```

## 8. 밸런싱

### 8.1 속성 밸런스 목표

**사용률 목표**:
```
각 속성: 18~22% (±2% 허용)

모니터링 지표:
- 속성별 캐릭터 사용률
- 속성별 승률
- 속성별 평균 클리어 시간
```

### 8.2 밸런스 조정 기준

**속성 너프 기준**:
- 사용률 25% 초과 2주 지속
- 승률 60% 초과
- 다른 속성 대비 우위가 명확

**속성 버프 기준**:
- 사용률 15% 미만 2주 지속
- 승률 40% 미만
- 사용 가치가 낮다는 피드백 다수
