## 1. 시스템 개요

### 1.1 기획 의도

> **💭 왜 이 시스템을 만드는가?**
>
> **지속 가능한 수익화**와 **공정한 무과금 경험**의 균형을 맞추기 위해, 투명한 확률과 명확한 가치 교환 구조를 설계했습니다.
>
> **핵심 목표**:
> - 💰 **건강한 수익 구조**: 가챠 50% + 월정액 25% + 편의성 25%로 안정적 매출
> - ⚖️ **무과금 존중**: 월 7,000~10,000 젬으로 메인 스토리 클리어 가능
> - 🎯 **가치 명확화**: 젬 1개 = 약 3원, 모든 패키지에 명확한 가치 제시
> - 🔒 **공정성 보장**: 천장 시스템(200회)으로 최악의 운도 보호
>
> **차별화 포인트**:
> - 일반 가챠 게임: 확률만 공개 → **본 시스템**: 천장 + 픽업 확률 + 기록 조회
> - 강제 과금 유도: 막힌 벽 → **본 시스템**: 무과금도 시간 투자로 돌파 가능
> - 복잡한 화폐: 10종 이상 → **본 시스템**: 골드 + 젬 + 스태미나 3가지 단순화
>
> **수익화 철학**:
> ```
> 무과금 유저: 게임 생태계의 기반 (커뮤니티, 바이럴)
>   → 느리지만 확실한 성장 경로 제공
>   → 월 7,000젬으로 챕터 6까지 도달
>
> 소액 과금 유저: 편의성 구매 ($10/월)
>   → 월정액으로 시간 절약 (젬 3,600 추가)
>   → 전투력 1.5배 정도 차이
>
> 고액 과금 유저: 빠른 컬렉션 완성 ($100+/월)
>   → 모든 컨텐츠 즉시 접근
>   → 전투력 3배 이상 (PvP 우위)
> ```
>
> **인플레이션 방지**:
> - 골드 싱크: 일일 획득 150K, 소비 120K (80% 회수)
> - 젬 싱크: 가챠(70%), 스태미나(15%), 편의(15%)
> - 스태미나: 자동 회복 + 레벨업 보너스로 자연스러운 플레이 리듬

### 1.2 시스템 목적
- 게임 내 재화 순환 구조 제공
- 플레이어의 진행과 성장 속도 조절
- 수익화와 게임 밸런스의 균형
- 장기 플레이 동기 부여

### 1.3 경제 시스템 핵심 원칙
- **Pay-to-Win 최소화**: 무과금도 충분히 즐길 수 있는 구조
- **시간 vs 돈**: 과금은 시간 절약의 개념
- **인플레이션 방지**: 화폐 싱크 시스템 운영
- **공정한 확률**: 가챠 확률 명시 및 천장 시스템

## 2. 화폐 시스템

### 2.1 골드 (기본 화폐)
**용도**:
- 캐릭터 레벨업
- 장비 강화
- 스킬 레벨업
- 일반 상점 구매
- 돌파 재료 구입

**획득처**:
```
주요 획득:
- 스테이지 클리어: 50~500 골드
- 일일 던전 (월요일): 대량 골드
- 퀘스트 보상: 1,000~10,000 골드
- 장비/아이템 판매: 판매가의 25%

부가 획득:
- 일일 출석: 5,000~50,000 골드
- 이벤트 보상
- 랭킹 보상
- 친구 선물
```

**골드 획득량 상세**:
```
스테이지별 골드 드롭:
- 챕터 1: 100~200 골드/스테이지
- 챕터 3: 300~500 골드/스테이지
- 챕터 5: 700~1,000 골드/스테이지
- 챕터 8: 1,500~2,500 골드/스테이지

일일 던전 (월요일 골드 던전):
- 초급: 10,000 골드 (스태미나 10)
- 중급: 30,000 골드 (스태미나 15)
- 고급: 80,000 골드 (스태미나 20)
- 최상급: 150,000 골드 (스태미나 30)

골드 효율: 스태미나 1당 2,500~5,000 골드
```

**소모처 및 비용**:
```
캐릭터 레벨업: 레벨 × 100 골드
장비 강화: 강화 레벨 × 등급 계수 × 1,000 골드
스킬 레벨업: 10,000 ~ 100,000 골드
돌파: 50,000 ~ 1,000,000 골드
```

**일일 획득량 (평균)**:
- 일반 플레이: 50,000~100,000 골드/일
- 골드 던전 활용: 150,000~250,000 골드/일
- 이벤트 기간: 300,000+ 골드/일

### 2.2 젬 (프리미엄 화폐)
**용도**:
- 프리미엄 뽑기
- 스태미나 회복
- 인벤토리 확장
- 골드 구매 (비효율)
- 프리미엄 상점 아이템

**획득처**:
```
무과금 획득:
- 메인 스토리 클리어: 챕터당 300~500 젬
- 일일 퀘스트: 50 젬/일
- 주간 퀘스트: 200 젬/주
- 업적 달성: 100~1,000 젬
- 아레나 랭킹: 주간 300~2,000 젬
- 이벤트 보상: 500~3,000 젬
- 보상형 광고: 10젬 × 5회/일

월간 무과금 획득량: 약 7,000~10,000 젬
```

**유료 패키지**:
| 패키지 | 가격 | 젬 | 보너스 | 비고 |
|--------|------|-----|--------|------|
| 소 | $0.99 | 100 | - | - |
| 중 | $4.99 | 550 | +10% | - |
| 대 | $9.99 | 1,200 | +20% | - |
| 특대 | $29.99 | 4,000 | +33% | - |
| 메가 | $49.99 | 7,500 | +50% | 월 1회 |
| 울트라 | $99.99 | 16,000 | +60% | 월 1회 |

**스타터 패키지** (첫 구매 한정):
- $4.99: 1,000젬 + 전설 뽑기권 × 1 + 스태미나 물약 × 10

**월정액 (30일)**:
- $9.99: 즉시 600젬 + 매일 100젬 (총 3,600젬)

### 2.3 스태미나 (행동력)
**기본 정보**:
- 최대치: 100 (확장 가능)
- 자동 회복: 5분당 1 스태미나
- 넘치는 회복: 불가 (최대치에서 멈춤)

**소모량**:
```
일반 스테이지: 5 스태미나
일일 던전: 20 스태미나
레이드: 50 스태미나
이벤트 던전: 10~30 스태미나
```

**회복 방법**:
```
자동 회복: 5분/1 (하루 288 스태미나)
레벨업: 전체 회복 + 최대치 초과 충전
스태미나 물약: +50 스태미나 (최대치 초과 가능)
젬 구매: 100젬 = 100 스태미나 (일 5회 제한)
친구 선물: +5 스태미나
일일 보상: +20 스태미나
```

### 2.4 기타 재화
**각성석**:
- 용도: 캐릭터 각성 및 최종 돌파
- 획득: 일일 던전 (토요일), 레이드, 이벤트

**강화석**:
- 용도: 장비 강화
- 획득: 일일 던전 (수요일), 스테이지 드롭

**스킬 북**:
- 용도: 스킬 레벨업
- 획득: 일일 던전 (목요일), 이벤트

**캐릭터 조각**:
- 용도: 캐릭터 소환, 돌파
- 획득: 가챠 중복, 일일 던전 (금요일)

```

## 4. 가챠 시스템

### 4.1 일반 가챠
**비용**: 골드 10,000 / 1회
**확률**:
- ★: 50%
- ★★: 35%
- ★★★: 15%
- ★★★★ 이상: 0%

**용도**:
- 초반 캐릭터 수집
- 각성 재료용 저등급 캐릭터 획득
- 골드 소모처 (경제 밸런스)

### 4.2 프리미엄 가챠
**비용**:
- 단일: 젬 300 / 1회
- 10+1: 젬 3,000 (10회 가격에 1회 무료)

**기본 확률**:
```
★: 40%
★★: 35%
★★★: 20%
★★★★: 4.5%
★★★★★: 0.5%
```

**천장 시스템**:
```
100회: ★★★★ 확정 (영웅 등급)
200회: ★★★★★ 확정 (전설 등급)

- 카운트는 영웅/전설 획득 시 초기화
- 화면에 현재 카운트 표시
- 법적 요구사항 준수
```

**가챠 연출 시스템**:
```
등급별 연출:
★: 은색 빛 → 빠른 카드 뒤집기
★★: 초록색 빛 → 일반 카드 뒤집기
★★★: 파란색 빛 → 빛나는 카드 뒤집기
★★★★: 보라색 빛 → 느린 카드 뒤집기 + 보이스
★★★★★: 황금빛 폭발 → 매우 느린 카드 뒤집기 + 전용 보이스 + 컷인

스킵 기능:
- 10+1 연속 뽑기 시 스킵 가능
- 결과만 즉시 표시
- 개별 확인 가능
```

**가챠 확률 검증 시스템**:
```
투명성 보장:
- 전체 확률 테이블 공개
- 개별 캐릭터 배출 확률 명시
- 뽑기 기록 저장 (최근 100회)
- 통계 데이터 제공 (개인별 누적)

법적 준수:
- 확률형 아이템 표시법 준수
- 미성년자 보호 장치
- 과금 한도 설정 기능
```

### 4.3 픽업 가챠 (기간 한정)
**특징**:
- 특정 캐릭터 배출 확률 2배
- 픽업 대상: 1~3명
- 이벤트 기간: 2주

**확률 예시**:
```
기본 ★★★★★ 확률: 0.5%
픽업 캐릭터: 0.3% (60%)
기타 ★★★★★: 0.2% (40%)
```

**천장**:
- 픽업 가챠 전용 천장 (200회)
- 도달 시 픽업 캐릭터 확정

### 4.4 확률 공개
**법적 준수**:
- 모든 아이템의 개별 획득 확률 명시
- 확률 변경 시 사전 공지
- 가챠 이력 조회 기능

## 6. 경제 밸런싱

### 6.1 화폐 싱크 (Currency Sink)
**목적**: 인플레이션 방지

**골드 싱크**:
- 강화 실패 시 골드 손실
- 레벨업 비용 증가
- 상점 구매
- 재조합 비용

**젬 싱크**:
- 스태미나 회복 (일일 제한으로 통제)
- 가챠 시스템
- 편의 기능 구매

**화폐 싱크 상세 설계**:
```
골드 싱크 비율 (일일 기준):
- 캐릭터 육성: 40% (레벨업, 돌파)
- 장비 강화: 35% (강화, 각성)
- 스킬 강화: 15% (스킬 레벨업)
- 상점 구매: 10% (소비 아이템)

목표: 일일 획득량의 80~120% 소비 유도
→ 플레이어가 항상 골드 필요성을 느끼되, 파산하지 않는 수준

젬 싱크 비율 (월간 기준):
- 가챠: 70% (프리미엄 10+1 뽑기)
- 스태미나 회복: 15% (급하게 진행 시)
- 편의 기능: 10% (인벤토리, 리셋)
- 외형 아이템: 5% (스킨, 이펙트)

목표: 무과금 유저는 가챠에 집중, 과금 유저는 다양한 용도 활용
```

### 6.2 인플레이션 방지 전략
**공급 제한**:
- 일일 던전 입장 제한
- 스태미나 시스템
- 상점 구매 제한

**수요 창출**:
- 신규 캐릭터 출시
- 강화 시스템의 확률적 요소
- 기간 한정 이벤트

### 6.3 무과금 vs 과금 밸런스
**무과금 유저 (1개월 플레이 기준)**:
```
획득 가능:
- 젬: 7,000~10,000
- 프리미엄 뽑기: 23~33회
- ★★★★ 캐릭터: 2~3명 (천장 미도달)
- ★★★★★ 캐릭터: 0~1명 (운에 따라)

진행도:
- 메인 스토리: 챕터 5~6 클리어 가능
- 평균 전투력: 8,000~12,000
```

**월 $10 유저 (월정액만 구매)**:

추가 획득:

진행도:
- 메인 스토리: 챕터 7~8 클리어 가능

**고액 과금 유저 (월 $100+)**:

획득:

- ★★★★★ 캐릭터: 5~10명
