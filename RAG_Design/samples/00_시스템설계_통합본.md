# 시스템 설계 통합본 - 퇴마 퍼즐

## 문서 개요

**프로젝트명**: 퇴마 퍼즐 (가제)
**문서 목적**: 게임의 모든 시스템 규칙을 정확하게 정의
**작성일**: 2024-10-30
**버전**: 2.0

이 문서는 개발팀 전체가 동일한 이해를 가질 수 있도록 각 시스템의 작동 원리, 수치 계산 공식, 조건과 제약사항을 명확히 기술합니다.

---

## 핵심 시스템 개요

**퇴마 퍼즐**의 게임플레이는 3개의 핵심 시스템이 유기적으로 연결되어 작동합니다:

1. **퍼즐 전투 시스템**: 매치-3 퍼즐 → 데미지 계산 → 승리/패배
2. **캐릭터 시스템**: 수집 (뽑기) → 성장 (레벨업/돌파/각성) → 파티 편성
3. **경제 시스템**: 화폐 획득 (스테이지/던전) → 소비 (강화/뽑기) → 순환

**플레이어 경험 흐름**:
```
스테이지 선택 (스태미나 소비)
    ↓
퍼즐 전투 (2-3분)
    ↓
보상 획득 (금화, 경험치, 재료, 캐릭터)
    ↓
캐릭터 강화 (즉시 사용 가능)
    ↓
다음 스테이지 도전
```

## 1. 퍼즐 전투 시스템 (Puzzle Combat System)

> **게임의 핵심**. 플레이어는 7x7 퍼즐 보드에서 같은 색 구슬 3개 이상을 매치하여 요괴에게 데미지를 입힙니다.
>
> "퍼즐앤드래곤"의 전략성 + "캔디크러쉬"의 접근성 = 쉽게 배우고 깊게 즐기는 퍼즐 전투

### 1.1 전투 시작 조건

**전투 진입 방식**:
- **메인 스테이지**: 챕터 맵에서 스테이지 선택 → 스태미나 10 소비
- **일일 던전**: 던전 메뉴에서 선택 → 스태미나 20 소비
- **PvP 아레나**: 아레나 메뉴에서 매칭 → 무료 티켓 1장 소비 (1일 5장 지급)
- **레이드**: 길드 메뉴에서 참여 → 레이드 티켓 1장 소비 (주 2회 지급)

**전투 시작 전 체크사항**:
1. 스태미나 또는 티켓 보유 확인
2. 파티 편성 완료 (리더 1명 + 서브 3명 = 총 4명)
3. 리더 스킬 활성화 여부 확인
4. 파티 총 전투력 표시 (권장 전투력과 비교)

### 1.2 퍼즐 전투 규칙

**전투 흐름**:
```
1. 전투 시작 → 퍼즐 보드 생성 (7x7, 5가지 색 구슬 랜덤 배치)
2. 플레이어 턴: 구슬 매치 (제한 시간 없음)
3. 데미지 계산 → 요괴 HP 감소 → 상태 이상 적용
4. 요괴 턴: 공격 → 플레이어 HP 감소
5. 2~4 반복
6. 승리 조건: 요괴 HP 0 / 패배 조건: 플레이어 HP 0
```

#### 1.2.1 퍼즐 보드 구조
**기본 정보**:
- 보드 크기: 7×7 (총 49칸)
- 속성 구슬: 5종 (화/수/목/금/토)
- 특수 구슬: 3종 (폭탄/레이저/무지개)

**구슬 색상과 속성**:
| 색상 | 속성 | 용도 |
|------|------|------|
| 빨강 | 화(火) | 화속성 공격 |
| 파랑 | 수(水) | 수속성 공격 |
| 초록 | 목(木) | 목속성 공격 |
| 노랑 | 금(金) | 금속성 공격 |
| 갈색 | 토(土) | 토속성 공격 |

**보드 생성 규칙**:
1. 게임 시작 시 5가지 색 구슬이 랜덤 배치
2. 시작 시 3개 이상 매치되는 구슬이 없도록 보장
3. 구슬이 터진 자리는 위에서 새 구슬이 떨어져 채움
4. 항상 매치 가능한 조합이 1개 이상 존재하도록 보장

#### 1.2.2 매치 규칙
**기본 매치**:
- 3매치: 같은 색 구슬 3개 일직선 (가로/세로) → 기본 공격
- 4매치: 같은 색 구슬 4개 일직선 → 특수 구슬 생성 (폭탄 or 레이저)
- 5매치: 같은 색 구슬 5개 이상 → 무지개 구슬 생성
- L자/T자 매치: 5개 이상 L자 또는 T자 형태 → 폭탄 구슬 생성

**특수 구슬 효과**:
1. **폭탄 구슬** (Bomb Orb)
   - 생성: 4매치 또는 L자/T자 5매치
   - 효과: 매치 시 주변 3×3 범위 구슬 파괴
   - 데미지: 기본 데미지 × 2.0

2. **레이저 구슬** (Laser Orb)
   - 생성: 4매치 (가로 또는 세로)
   - 효과: 매치 시 같은 줄(가로 or 세로) 전체 파괴
   - 데미지: 기본 데미지 × 2.5

3. **무지개 구슬** (Rainbow Orb)
   - 생성: 5매치 이상
   - 효과: 매치 시 보드 상의 같은 색 구슬 전체 파괴
   - 데미지: 기본 데미지 × 3.0
   - 특수: 모든 속성으로 인정 (어떤 구슬과도 매치 가능)

**연쇄 (Chain) 시스템**:
- 한 번의 턴에 여러 번 매치가 연속으로 발생하면 연쇄 카운트
- 연쇄마다 데미지 +10% (최대 +50%)
- 예시: 1연쇄 100%, 2연쇄 110%, 3연쇄 120%, ..., 6연쇄 이상 150%

**콤보 (Combo) 시스템**:
- 한 번의 턴에 여러 개의 매치가 동시에 발생하면 콤보 카운트
- 콤보마다 데미지 +5% (최대 +25%)
- 예시: 1콤보 100%, 2콤보 105%, 3콤보 110%, ..., 6콤보 이상 125%

### 1.3 데미지 계산 공식

#### 1.3.1 물리 데미지
```
최종 데미지 = [(공격력 × 스킬 배율) - (방어력 × 방어 계수)] ×
             속성 상성 보정 ×
             크리티컬 보정 ×
             버프/디버프 보정 ×
             랜덤 보정(0.95~1.05)
```

**세부 계산**:
- 공격력: 기본 공격력 + 무기 공격력 + 레벨 보너스 + 스탯 보너스
- 방어 계수: 0.5 (방어력이 데미지를 50% 효율로 감소)
- 최소 데미지 보장: 계산 결과가 1 미만일 경우 1로 고정

#### 1.3.2 마법 데미지
```
최종 데미지 = [(마력 × 스킬 배율) - (마법 저항력 × 저항 계수)] ×
             속성 상성 보정 ×
             크리티컬 보정 ×
             버프/디버프 보정 ×
             랜덤 보정(0.95~1.05)
```

#### 1.3.3 크리티컬 시스템
**크리티컬 발동 조건**:
- 크리티컬 확률 = 기본 크리티컬 확률(5%) + 캐릭터 크리티컬 스탯 + 장비 보너스
- 크리티컬 발동 시 데미지 배율 = 150% + (크리티컬 데미지 스탯 × 1%)

**크리티컬 특수 효과**:
- 특정 스킬의 경우 크리티컬 발동 시 추가 효과 발생
- 크리티컬 누적 시 피버 게이지 증가량 2배

### 1.4 속성 시스템

#### 1.4.1 속성 타입
- 화(火): 불 속성
- 수(水): 물 속성
- 목(木): 나무 속성
- 뢰(雷): 번개 속성
- 토(土): 땅 속성
- 빛(光): 빛 속성
- 암(闇): 어둠 속성
- 무(無): 무속성

#### 1.4.2 속성 상성표
| 공격\방어 | 화 | 수 | 목 | 뢰 | 토 | 빛 | 암 | 무 |
|----------|----|----|----|----|----|----|----|----|
| 화 | 100% | 50% | 150% | 100% | 100% | 100% | 100% | 100% |
| 수 | 150% | 100% | 50% | 50% | 100% | 100% | 100% | 100% |
| 목 | 50% | 150% | 100% | 150% | 100% | 100% | 100% | 100% |
| 뢰 | 100% | 150% | 50% | 100% | 50% | 100% | 100% | 100% |
| 토 | 100% | 100% | 100% | 150% | 100% | 100% | 100% | 100% |
| 빛 | 100% | 100% | 100% | 100% | 100% | 100% | 150% | 100% |
| 암 | 100% | 100% | 100% | 100% | 100% | 150% | 100% | 100% |
| 무 | 100% | 100% | 100% | 100% | 100% | 100% | 100% | 100% |

**속성 보정 효과**:
- 유리(150%): 데미지 1.5배, "효과는 굉장했다!" 메시지 표시
- 보통(100%): 데미지 변화 없음
- 불리(50%): 데미지 0.5배, "효과가 별로인 것 같다..." 메시지 표시

### 1.5 상태 이상 시스템

#### 1.5.1 상태 이상 종류
**독 (Poison)**:
- 효과: 턴 종료 시 최대 HP의 5% 고정 데미지
- 지속: 3턴
- 해제: 해독제 사용, 상태 이상 회복 스킬, 전투 종료
- 중첩: 최대 3중첩, 중첩 시 데미지 5%씩 증가

**화상 (Burn)**:
- 효과: 턴 종료 시 공격력의 50%만큼 데미지
- 지속: 5턴
- 해제: 물 속성 스킬 피격, 상태 이상 회복, 전투 종료
- 특이사항: 방어력 무시 데미지

**마비 (Paralysis)**:
- 효과: 30% 확률로 행동 불가
- 지속: 3턴
- 해제: 마비 회복 아이템, 상태 이상 회복 스킬, 전투 종료
- 추가 효과: 회피율 -50%

**빙결 (Freeze)**:
- 효과: 행동 완전 불가
- 지속: 1턴
- 해제: 화염 속성 공격 피격 시 즉시 해제, 턴 경과
- 특이사항: 빙결 중 물리 공격 피격 시 데미지 1.5배

**기절 (Stun)**:
- 효과: 행동 불가, 턴 건너뜀
- 지속: 1턴
- 해제: 자동 해제 (지속 시간 종료)
- 특이사항: 기절 중 받는 모든 데미지 1.2배

**수면 (Sleep)**:
- 효과: 행동 불가, 턴 건너뜀
- 지속: 2턴
- 해제: 데미지 피격 시 즉시 해제
- 특이사항: 수면 중 첫 공격 크리티컬 확정

**혼란 (Confusion)**:
- 효과: 50% 확률로 아군 공격
- 지속: 2턴
- 해제: 상태 이상 회복, 피격 시 30% 확률로 해제
- 특이사항: 혼란 중 자신을 공격할 수도 있음

**침묵 (Silence)**:
- 효과: 스킬 사용 불가 (일반 공격만 가능)
- 지속: 3턴
- 해제: 침묵 회복 아이템, 상태 이상 회복 스킬
- 특이사항: 패시브 스킬은 정상 작동

#### 1.5.2 상태 이상 저항
```
상태 이상 적용 확률 = 기본 확률 × (1 - 대상 저항력)
```

**저항력 계산**:
- 기본 저항력: 0%
- 장비/스킬을 통한 저항력: 최대 75%까지 상승 가능
- 보스 몬스터: 기본 저항력 50%

**면역**:
- 특정 캐릭터/몬스터는 특정 상태 이상에 완전 면역
- 예: 불 정령 → 화상 면역, 기계 타입 → 독 면역

### 1.6 버프/디버프 시스템

#### 1.6.1 능력치 버프/디버프
**공격력 증가/감소**:
- 1단계: ±15%
- 2단계: ±30%
- 3단계: ±50%
- 최대 중첩: 3단계
- 지속 시간: 3~5턴 (스킬별 상이)

**방어력 증가/감소**:
- 1단계: ±15%
- 2단계: ±30%
- 3단계: ±50%
- 최대 중첩: 3단계
- 지속 시간: 3~5턴

**속도 증가/감소**:
- 1단계: ±20%
- 2단계: ±40%
- 3단계: ±60%
- 최대 중첩: 3단계
- 영향: 턴 순서, 회피율, 크리티컬 확률

#### 1.6.2 특수 버프
**무적 (Invincible)**:
- 효과: 모든 데미지 무효화
- 지속: 1~2턴 또는 피격 1~2회
- 제약: 해당 캐릭터는 행동 불가 (일부 스킬 예외)

**반사 (Reflect)**:
- 효과: 받은 데미지의 X% 공격자에게 반사
- 지속: 3턴 또는 피격 3회
- 종류:
  - 물리 반사: 물리 데미지만 반사
  - 마법 반사: 마법 데미지만 반사
  - 전체 반사: 모든 데미지 반사

**재생 (Regeneration)**:
- 효과: 턴 종료 시 최대 HP의 X% 회복
- 지속: 5턴
- 회복량: 10% (1단계), 15% (2단계), 20% (3단계)
- 최대 중첩: 3단계

**흡혈 (Lifesteal)**:
- 효과: 준 데미지의 X% HP 회복
- 지속: 3턴
- 흡혈률: 30% (1단계), 50% (2단계), 70% (3단계)

#### 1.6.3 버프/디버프 우선순위
동일한 효과가 중복될 경우:
1. 높은 단계의 효과가 우선
2. 동일 단계일 경우 나중에 적용된 효과로 갱신
3. 지속 시간은 새로 적용된 시간으로 초기화

### 1.7 전투 종료 조건

#### 1.7.1 승리 조건
- 모든 적 처치
- 특정 목표 달성 (호위, 생존, 아이템 획득 등)
- 제한 시간 내 조건 달성

#### 1.7.2 패배 조건
- 아군 전멸
- 핵심 유닛 사망 (해당되는 경우)
- 제한 시간 초과
- 임무 실패 (특정 조건 미달성)

#### 1.7.3 도망
**도망 성공 조건**:
```
도망 성공률 = 30% + (아군 평균 속도 - 적 평균 속도) / 적 평균 속도 × 50%
```
- 최소 성공률: 10%
- 최대 성공률: 90%
- 보스전: 도망 불가
- 도망 실패 시: 턴 소모, 적의 선제 공격

## 2. 캐릭터 성장 시스템

### 2.1 레벨 시스템

#### 2.1.1 경험치 획득
**경험치 획득처**:
- 전투 승리: 적 레벨 × 기본 경험치(100)
- 퀘스트 완료: 퀘스트별 고정 경험치
- 아이템 사용: 경험치 물약 (소: 1,000 / 중: 5,000 / 대: 25,000)
- 일일 던전: 경험치 던전 클리어 시 대량 경험치

**경험치 보정**:
```
획득 경험치 = 기본 경험치 × 레벨 차이 보정 × 경험치 부스트
```

**레벨 차이 보정**:
- 적 레벨이 높을 경우: +10% per level (최대 +100%)
- 적 레벨이 낮을 경우: -10% per level (최소 10%)

**경험치 부스트**:
- VIP 보너스: +20%
- 프리미엄 패스: +30%
- 이벤트 기간: +50%
- 경험치 부스트 아이템: +100% (1시간)

#### 2.1.2 레벨업 필요 경험치
```
필요 경험치 = 100 × (현재 레벨)^1.5 + 500
```

**레벨별 필요 경험치 예시**:
| 레벨 | 필요 경험치 | 누적 경험치 |
|------|------------|------------|
| 1→2 | 600 | 600 |
| 2→3 | 783 | 1,383 |
| 5→6 | 1,618 | 6,528 |
| 10→11 | 3,662 | 29,340 |
| 20→21 | 9,444 | 129,720 |
| 50→51 | 35,855 | 1,234,567 |
| 99→100 | 99,500 | 6,789,012 |

#### 2.1.3 레벨업 보상
**자동 증가 스탯**:
- HP: +50 + (레벨 × 10)
- 공격력: +5 + (레벨 × 2)
- 방어력: +3 + (레벨 × 1)
- 마력: +5 + (레벨 × 2)
- 속도: +2 + (레벨 × 0.5)

**추가 보상**:
- 스탯 포인트: 레벨당 5포인트
- 스킬 포인트: 5레벨마다 1포인트
- 골드: 레벨 × 100
- 특정 레벨 달성 보상 (10, 20, 30, 50, 100 레벨)

### 2.2 스탯 시스템

#### 2.2.1 기본 스탯
**힘 (STR - Strength)**:
- 영향:
  - 물리 공격력: 힘 × 2
  - 물리 크리티컬 데미지: 힘 × 0.1%
  - 무게 제한: 힘 × 10
- 추천: 전사, 기사 계열

**민첩 (AGI - Agility)**:
- 영향:

  - 회피율: 민첩 × 0.2%

  - 턴 순서: 민첩 직접 반영
- 추천: 도적, 궁수 계열

**체력 (VIT - Vitality)**:
- 영향:
  - 최대 HP: 체력 × 20
  - HP 재생: 체력 × 0.5 per 턴
  - 상태 이상 저항: 체력 × 0.1%
- 추천: 탱커 계열

**지능 (INT - Intelligence)**:
- 영향:
  - 마법 공격력: 지능 × 2.5
  - 최대 MP: 지능 × 10
  - 마법 크리티컬 데미지: 지능 × 0.1%
- 추천: 마법사 계열

**정신 (WIS - Wisdom)**:
- 영향:
  - 마법 방어력: 정신 × 1.5
  - MP 재생: 정신 × 0.3 per 턴
  - 치유 효과: 정신 × 0.5%
- 추천: 힐러, 서포터 계열

**행운 (LUK - Luck)**:
- 영향:
  - 아이템 드롭률: 행운 × 0.2%
  - 크리티컬 확률: 행운 × 0.05%
  - 회피율: 행운 × 0.1%
  - 상태 이상 저항: 행운 × 0.05%
  - 행운 판정 (일부 이벤트)
- 추천: 모든 캐릭터에게 유용

#### 2.2.2 스탯 포인트 배분
- 레벨업 시 획득한 스탯 포인트 자유 배분

  - 1회: 무료 (튜토리얼)

  - 3회 이후: 500 젬 (고정)

#### 2.2.3 스탯 한계
- 스탯 포인트로 올릴 수 있는 최대치: 999
- 장비/버프 포함 최종 스탯: 9,999

### 2.5 장비 강화 시스템

#### 2.5.1 강화 기본 규칙
**강화 레벨**:
- 최대 강화: +15
- 안전 강화: +5까지 실패 없음
- 위험 강화: +6부터 실패 가능성

**강화 성공률**:
| 강화 레벨 | 성공률 | 실패 시 |
|----------|--------|---------|
| +0 → +5 | 100% | - |
| +5 → +6 | 80% | 강화 레벨 유지 |
| +6 → +7 | 70% | 강화 레벨 유지 |
| +7 → +8 | 60% | +6으로 하락 |
| +8 → +9 | 50% | +7로 하락 |
| +9 → +10 | 40% | +8로 하락 |
| +10 → +11 | 30% | +9로 하락 |
| +11 → +12 | 25% | +9로 하락 |
| +12 → +13 | 20% | +10으로 하락 |
| +13 → +14 | 15% | +10으로 하락 |
| +14 → +15 | 10% | +10으로 하락 |

**강화 비용**:
```
강화 비용 = 기본 비용 × (장비 등급 계수) × (강화 레벨 + 1)
```
- 기본 비용: 1,000 골드
- 등급 계수: 일반(1), 고급(2), 희귀(4), 영웅(8), 전설(16)

#### 2.5.2 강화 효과
**능력치 증가**:
```
강화 시 증가량 = 기본 능력치 × (강화 레벨 × 5%)
```

**예시**:
- 기본 공격력 100인 무기를 +10 강화 시
- 최종 공격력 = 100 + (100 × 50%) = 150

**특수 효과**:
- +5: 추가 옵션 1개 랜덤 부여
- +10: 세트 효과 강화 (세트 장비일 경우)
- +15: 빛나는 효과 + 추가 옵션 1개 + 능력치 10% 추가 증가

#### 2.5.3 강화 보호/보조 아이템
**강화 보호권**:
- 효과: 강화 실패 시 레벨 하락 방지
- 적용 범위: +7 이상 강화 시 사용 가능
- 획득: 이벤트, 상점 구매

**강화 성공률 증가권**:
- 효과: 성공률 +10% 증가
- 적용 범위: +6 이상 강화 시 사용 가능
- 최대 중첩: 5개 (+50%)
- 획득: 이벤트, 상점 구매

**강화 축복 주문서**:
- 효과: 실패 시 레벨 하락 없음 + 성공률 +5%
- 적용 범위: +10 이상
- 획득: 레이드, 특별 이벤트

## 7. 밸런싱 규칙

### 7.1 전투력 계산
```
전투력 = (공격력 × 3) + (방어력 × 2) + (HP / 10) +
         (크리티컬 확률 × 100) + (크리티컬 데미지 × 50) +
         (속도 × 5) + (스킬 레벨 합계 × 100)
```

### 7.2 난이도 곡선
**적 능력치 스케일링**:
```
적 능력치 = 기본 능력치 × (1 + 스테이지 레벨 × 0.1)^1.2
```

**보스 능력치**:
```
보스 능력치 = 일반 적 능력치 × 5
보스 HP = 일반 적 HP × 10
```

### 7.3 보상 스케일링
```
보상량 = 기본 보상 × (1 + 난이도 계수) × (1 + 클리어 등급 보너스)
```

### 7.4 인플레이션 방지
**화폐 싱크 (Currency Sink)**:
- 거래소 수수료: 15%
- 강화 실패 시 비용 손실
- 제작 비용
- 정기적인 골드 사용 이벤트

**아이템 싱크**:
- 장비 분해 시 재료 회수율 50%
- 강화 실패 시 재료 소모
- 기간 한정 아이템

```
  └─ 보상 시스템 (클리어 보상)

소셜 시스템
  ├─ 길드 시스템 (협동)
  ├─ 친구 시스템 (지원)
  └─ PvP 시스템 (경쟁)
```

### 9.2 핵심 게임 루프와 시스템 연계
```
[단기 루프] (1회 플레이 세션)
스태미나 소모 → 던전 입장 → 전투 시스템 작동 →
보상 획득 (경제 시스템) → 캐릭터 강화 (성장 시스템) →
전투력 상승 → 다음 던전 도전

[중기 루프] (일일/주간)
일일 퀘스트 (리텐션 시스템) → 보상 수집 →
장비 강화 (강화 시스템) → PvP 참여 (소셜/경쟁 시스템) →
랭킹 상승 → 주간 보상

[장기 루프] (월간/시즌)
시즌 목표 설정 → 엔드게임 콘텐츠 (레이드) →
전설 아이템 획득 → 최종 강화 → 랭킹 경쟁 →
시즌 보상 → 새 시즌
```

## 부록: 용어 정리

| 용어 | 설명 |
|------|------|
| 스태미나 | 던전 입장에 필요한 자원 |
| 전투력 | 캐릭터의 종합 능력을 수치화한 값 |
| 천장 시스템 | 일정 횟수 뽑기 시 최고 등급 확정 |
| 귀속 | 거래 불가 상태의 아이템 |
| 버프 | 능력치를 일시적으로 증가시키는 효과 |
| 디버프 | 능력치를 일시적으로 감소시키는 효과 |
| DPS | Damage Per Second (초당 데미지) |
| 탱커 | 높은 방어력으로 적의 공격을 받아내는 역할 |
| 딜러 | 높은 공격력으로 적에게 데미지를 주는 역할 |
| 힐러 | 아군의 HP를 회복시키는 역할 |
| 서포터 | 버프/디버프로 팀을 지원하는 역할 |
| 기여도 | 협동 콘텐츠에서 개인의 활약을 수치화한 값 |
| MVP | 가장 높은 기여도를 기록한 플레이어 |
