## 1. 설계 개요

### 1.1 기획 의도

> **💭 왜 이 시스템을 만드는가?**
>
> **한국 전통 요괴**를 현대적으로 재해석하여 **문화적 차별화**와 **전략적 전투**를 동시에 구현합니다.
>
> **핵심 목표**:
> - 🎭 **문화 콘텐츠**: 도깨비, 구미호, 물귀신 등 한국 요괴로 정체성 확보
> - 🎯 **학습 곡선**: 일반 → 엘리트 → 보스 → 최종보스 단계적 난이도 상승
> - 🧠 **패턴 학습**: 예고 시스템으로 대응 방법 학습 유도 (운 < 실력)
> - 💎 **보상 연계**: 몬스터 등급과 보상 가치 연동으로 도전 동기 부여
>
> **차별화 포인트**:
> - 서양 판타지: 드래곤/고블린 → **본 시스템**: 도깨비/구미호/처녀귀신
> - 단순 체력: HP만 높음 → **본 시스템**: 패턴 + 페이즈 + 기믹 복합 설계
> - 예측 불가: 랜덤 공격 → **본 시스템**: 패턴 예고로 대비 가능 (전략성)
>
> **한국 요괴 모티브 활용**:
> ```
> 도깨비 (화속성):
> - 외형: 불방망이, 뿔, 호랑이 가죽
> - 패턴: 공격적, 버프 중심, 화상 부여
> - 스토리: "도깨비불이 춤추는 밤..."
>
> 구미호 (목속성):
> - 외형: 아홉 꼬리, 여우 귀
> - 패턴: 매혹 상태이상, 흡혈, 속임수
> - 스토리: "천년을 살아 인간이 되려던..."
>
> 물귀신 (수속성):
> - 외형: 젖은 머리카락, 창백한 피부
> - 패턴: 빙결, 익사 공격, 체력 흡수
> - 스토리: "물가에 홀로 있는 여인을 조심하라"
> ```
>
> **AI 설계 철학**:
> - **일반 몬스터**: 단순 우선순위 (HP 낮은 대상 공격)
> - **엘리트**: 조건부 패턴 (HP 50% 이하 시 강공격)
> - **보스**: 페이즈 전환 + 소환 + 전멸기 복합 기믹
> - **예고 시스템**: 3턴 전 경고로 플레이어에게 준비 시간 제공
>
> **난이도 곡선**:
> ```
> 챕터 1-3: 튜토리얼 (단순 패턴, 여유 시간)
> 챕터 4-6: 학습 단계 (복합 패턴, 타이밍 중요)
> 챕터 7-8: 숙련 요구 (페이즈 전환, 기믹 이해 필수)
> 엔드 게임: 최적화 필요 (속성 카운터, 완벽한 파티 구성)
> ```

### 1.2 설계 목적
- 다양한 전투 경험 제공
- 난이도 곡선 설계
- 전략적 파티 구성 유도
- 보상 체계와 연계

### 1.3 핵심 원칙
**"한국 전통 요괴 모티브 + 전략적 패턴 설계"**

## 2. 몬스터 분류

### 2.1 등급 체계

| 등급 | HP 범위 | ATK 범위 | 패턴 개수 | 페이즈 | 특징 |
|------|---------|----------|-----------|--------|------|
| **일반** | 500~1,500 | 80~200 | 1개 | - | 1~9 스테이지, 단순 패턴, 기본 재료 |
| **엘리트** | 1,200~2,000 | 150~250 | 2~3개 | - | 3/6/9 스테이지, 특수 스킬 1개, 고급 재료 |
| **보스** | 2,500~4,000 | 200~350 | 4~5개 | 2~3 | 챕터 최종(10), 특수 스킬 2~3개, 희귀 재료 |
| **최종 보스** | 5,000~10,000 | 350~500 | 6~8개 | 3~4 | 메인 스토리 종료, 특수 기믹, 레전더리 재료 |

### 2.2 속성 분류

**5대 속성 몬스터**:
```
화 (火) 몬스터:
- 도깨비 계열
- 불꽃 공격
- 화상 상태이상
- 공격적인 패턴

수 (水) 몬스터:
- 물귀신 계열
- 얼음/물 공격
- 빙결 상태이상
- 방어적인 패턴

목 (木) 몬스터:
- 정령 계열
- 독/회복 스킬
- 독 상태이상
- 지원형 패턴

금 (金) 몬스터:
- 뇌전 계열
- 번개 공격
- 감전 상태이상
- 빠른 공격

토 (土) 몬스터:
- 암석 계열
- 물리 공격
- 석화 상태이상
- 탱커형 패턴
```

**무속성 몬스터**:
```
특징:
- 특수 보스만 해당
- 속성 상성 무시
- 모든 속성 공격 사용
- 최고 난이도
```

## 3. 패턴 시스템

### 3.1 기본 패턴

| 패턴명 | 대상 | 데미지 배율 | 쿨타임 | 예고 메시지 | 색상 |
|--------|------|-------------|--------|-------------|------|
| **단일 공격** | 아군 1명 (HP 낮은 순) | ATK × 1.0 | 1턴 | "다음: 공격" | 회색 |
| **광역 공격** | 아군 전체 | ATK × 0.6 | 3턴 | "다음: 광역공격" | 주황색 |
| **강공격** | 아군 1명 | ATK × 2.0 | 5턴 | "다음: 강공격" | 빨간색 |

### 3.2 특수 패턴

**버프 스킬**:
```
자신의 공격력 증가:
- 효과: ATK +30%
- 지속: 3턴
- 쿨타임: 7턴
- 예고: "다음: 강화"

자신의 방어력 증가:
- 효과: DEF +50%
- 지속: 2턴
- 쿨타임: 6턴
- 예고: "다음: 방어"
```

**디버프 스킬**:
```
공격력 감소:
- 대상: 아군 전체
- 효과: ATK -20%
- 지속: 2턴
- 쿨타임: 5턴

방어력 감소:
- 대상: 아군 1명
- 효과: DEF -30%
- 지속: 3턴
- 쿨타임: 6턴
```

**상태이상 부여**:
```
화상:
- 속성: 화
- 확률: 30%
- 피해: ATK * 0.15/턴
- 지속: 3턴

빙결:
- 속성: 수
- 확률: 50%
- 효과: 1턴 행동불가
- 지속: 1턴

독:
- 속성: 목
- 확률: 40%
- 피해: HP최대 * 0.05/턴
- 지속: 4턴
```

**회복 스킬**:
```
자가 회복:
- 회복량: HP최대 * 0.2
- 쿨타임: 8턴
- 조건: HP 30% 이하
- 예고: "다음: 회복" (초록색)
```

### 3.3 보스 전용 패턴

**페이즈 전환**:
```
조건: HP 70%, 40% 도달
효과:
- 즉시 행동
- 광역 공격
- 버프 부여
- 패턴 변경

예:
HP 70%: "분노 모드!" + ATK +50%
HP 40%: "폭주 모드!" + SPD +30%
HP 10%: "최후의 일격!" + 전멸기
```

**소환 패턴**:
```
조작:
- 몬스터 1~2마리 소환
- 쿨타임: 10턴
- 조건: HP 50% 이하

소환물:
- HP: 보스의 20%
- ATK: 보스의 50%
- 처치 시 보상 없음
```

**전멸기**:
```
조건: HP 10% 이하
데미지: ATK * 5.0 (전체)
쿨타임: 없음 (1회만)
예고: "위험: 전멸기!" (3턴 전 경고)
대응: 방어 스킬 필수
```

## 4. 난이도 설계

### 4.1 스테이지별 난이도

**초반 (1~3장)**:
```
목표: 튜토리얼 및 학습
특징:
- 단순한 패턴
- 낮은 HP/ATK
- 속성 상성 학습
- 여유로운 턴 수

권장 레벨: 1~20
권장 전투력: 500~3,000
```

**중반 (4~6장)**:
```
목표: 전략 요구
특징:
- 복합 패턴
- 중간 HP/ATK
- 파티 구성 중요
- 타이밍 중요

권장 레벨: 20~40
권장 전투력: 3,000~8,000
```

**후반 (7~10장)**:
```
목표: 고난이도 도전
특징:
- 복잡한 패턴
- 높은 HP/ATK
- 최적화 필수
- 장비/스킬 강화 필수

권장 레벨: 40~60
권장 전투력: 8,000~18,000
```

**엔드 콘텐츠**:
```
목표: 극한 도전
특징:
- 극악 난이도
- 최상급 장비 필요
- 완벽한 파티 구성
- 숙련도 필요

권장 레벨: 80~100
권장 전투력: 35,000~60,000
```

### 4.2 난이도 조절 요소

**HP 배율**:
```
스테이지별 증가:
1-1: 100%
1-5: 120%
1-10: 150% (보스)
2-1: 160%
2-10: 200% (보스)
...
10-10: 500% (최종보스)
엔드: 800%~1500%
```

**ATK 배율**:
```
스테이지별 증가:
1-1: 100%
1-10: 130%
2-10: 170%
5-10: 290%
10-10: 350%
엔드: 500%~800%
```

**패턴 복잡도**:
```
초반: 1~2개 패턴
중반: 2~3개 패턴
후반: 3~5개 패턴
엔드: 6~8개 패턴 + 기믹
```

## 5. AI 행동 패턴

### 5.1 일반 몬스터 AI

**기본 우선순위**:
```
1. HP 30% 이하 → 회복 스킬
2. 쿨타임 완료된 강공격
3. 쿨타임 완료된 광역공격
4. 기본 공격
5. 대기 (스킬 충전)
```

**타겟 선택**:
```
단일 공격:
- 우선순위 1: HP 가장 낮은 캐릭터
- 우선순위 2: 공격력 가장 높은 캐릭터
- 우선순위 3: 리더

광역 공격:
- 대상: 전체

버프:
- 대상: 자신
```

### 5.2 보스 몬스터 AI

**페이즈별 우선순위**:
```
페이즈 1 (HP 100%~70%):
- 기본 패턴 중심
- 가끔 특수 스킬

페이즈 2 (HP 70%~40%):
- 버프 사용 증가
- 강공격 빈도 증가
- 소환 패턴 사용

페이즈 3 (HP 40%~10%):
- 광역 공격 위주
- 디버프 집중 사용
- 연속 공격

페이즈 4 (HP 10% 이하):
- 전멸기 준비
- 자가 버프
- 최후의 발악
```

**패턴 선택 로직**:
```python
def select_pattern(boss):
    if boss.hp_percent <= 10:
        return "전멸기"
    elif boss.hp_percent <= 40 and can_summon():
        return "소환"
    elif is_on_cooldown("강공격") == False:
        return "강공격"
    elif boss.hp_percent <= 70 and need_buff():
        return "버프"
    else:
        return "기본공격"
```

### 5.3 적응형 AI

**플레이어 파티 분석**:
```
속성 구성 파악:
- 아군 속성 분포 확인
- 약점 속성 집중 공격

전투력 분석:
- 평균 HP 파악
- 공격 패턴 조절
- 난이도 동적 조정
```

**학습형 패턴**:
```
같은 스테이지 재도전 시:
- 이전 전투 데이터 참조
- 효과적이었던 패턴 우선 사용
- 플레이어가 대응 못한 패턴 반복

단, 학습 상한:
- 최대 3회까지만 학습
- 너무 어려워지지 않도록 제한
```

## 7. 특수 몬스터

### 7.1 레어 몬스터

**황금 도깨비**:
```
특징:
- 랜덤 등장 (5% 확률)
- 매우 낮은 HP (100)
- 높은 방어력 (999)
- 3턴 후 도주

드롭:
