## 1. 설계 개요

### 1.1 기획 의도

> **💭 왜 이 UI/UX를 설계하는가?**
>
> 모바일 게임의 생명은 **첫 3초**입니다. 복잡한 UI로 인한 이탈을 막고, **직관적 조작**과 **즉각적 피드백**으로 몰입을 극대화합니다.
>
> **핵심 목표**:
> - 👆 **원터치 원칙**: 모든 주요 기능 1번의 터치로 접근
> - ⚡ **3초 이해**: 처음 본 화면도 3초 안에 기능 파악 가능
> - 🎮 **편손 플레이**: 한 손으로 모든 조작 가능 (출퇴근 시간 타겟)
> - 📱 **반응형 설계**: 다양한 화면 비율(18:9~21:9) 대응
>
> **차별화 포인트**:
> - 일반 퍼즐 게임: 정보 과다 → **본 시스템**: 4단 레이아웃으로 정보 계층화
> - 복잡한 네비게이션: 3~4단계 메뉴 → **본 시스템**: 하단 고정 메뉴로 1단계 접근
> - 단조로운 피드백: 숫자만 표시 → **본 시스템**: 시각+음향+촉각 3중 피드백
>
> **모바일 최적화 원칙**:
> ```
> 터치 영역: 최소 60x60px (애플 가이드라인 44pt 이상)
> 중요 버튼: 화면 하단 1/3 영역 배치 (엄지 도달 범위)
> 정보 표시: 상단 1/4 영역 (시선 자연 흐름)
> 게임플레이: 중앙 50% (집중 영역)
> ```
>
> **피드백 설계 철학**:
> - 매치 성공: 0.3초 이내 시각 피드백 (즉각성)
> - 연쇄 발생: 음계 상승 + 텍스트 확대 (성취감)
> - 크리티컬: 화면 플래시 + 별 파티클 (특별함)
> - 스킬 발동: 2~3초 컷인 연출 (카타르시스)
>
> **접근성 고려**:
> - 색맹 모드: 아이콘 + 색상 조합 (색만 의존 금지)
> - 저시력 모드: UI 150% 확대 옵션
> - 모션 멀미: 화면 흔들림 감소 옵션

### 1.2 설계 목적
- 직관적이고 쉬운 사용성 제공
- 빠른 정보 파악과 의사결정 지원
- 몰입감 있는 게임 경험
- 모바일 환경 최적화

### 1.3 핵심 원칙
**"3초 안에 이해하고, 1터치로 실행한다"**

## 2. 전투 화면 UI

### 2.1 화면 레이아웃

```
┌─────────────────────────────────────┐
│ ┌─────┐  [스킬게이지]   [⏱ 00:28] │ ← 상단 바 (10%)
│ │ HP  │   ████████░░░               │
│ └─────┘                             │
├─────────────────────────────────────┤
│                                     │
│         [요괴 표시 영역]            │ ← 적 영역 (25%)
│      👹 HP: ████████░░              │
│      [다음 패턴: 강공격]            │
│                                     │
├─────────────────────────────────────┤
│ ┌─┬─┬─┬─┬─┬─┬─┐                     │
│ │ │ │ │ │ │ │ │                     │
│ ├─┼─┼─┼─┼─┼─┼─┤                     │
│ │ │ │ │ │ │ │ │   [퍼즐 보드]      │ ← 보드 영역 (50%)
│ ├─┼─┼─┼─┼─┼─┼─┤      7x7           │
│ │ │ │ │ │ │ │ │                     │
│ ├─┼─┼─┼─┼─┼─┼─┤                     │
│ │ │ │ │ │ │ │ │                     │
│ └─┴─┴─┴─┴─┴─┴─┘                     │
├─────────────────────────────────────┤
│ [캐1] [캐2] [캐3] [캐4]             │ ← 캐릭터 바 (15%)
│ [스킬][스킬][스킬][스킬] [⚙️][❚❚]   │
└─────────────────────────────────────┘
```

### 2.2 상단 UI 요소

**HP 바**:
```
위치: 좌측 상단
크기: 전체 너비의 30%
표시:
- 현재 HP / 최대 HP (숫자)
- HP 바 (색상 그라데이션)
  · 녹색: 70~100%
  · 노란색: 30~69%
  · 빨간색: 0~29%
- HP 변동 애니메이션 (0.3초)
```

**스킬 게이지**:
```
위치: 중앙 상단
크기: 전체 너비의 40%
표시:
- 게이지 바 (0~100%)
- 충전 중: 파란색
- 충전 완료: 황금색 + 반짝임
- 퍼센트 숫자 표시
```

**타이머**:
```
위치: 우측 상단
크기: 전체 너비의 20%
표시:
- MM:SS 형식
- 10초 이하: 빨간색 + 깜빡임
- 5초 이하: 빠른 깜빡임 + 경고음
```

### 2.3 요괴 표시 영역

**요괴 모델**:
```
크기: 화면 높이의 20%
위치: 중앙 정렬
애니메이션:
- Idle: 호흡 애니메이션 (반복)
- 공격: 공격 모션 (1초)
- 피격: 흔들림 + 데미지 숫자 (0.5초)
- 사망: 사라짐 연출 (1초)
```

**HP 바**:
```
위치: 요괴 하단
너비: 요괴 너비의 120%
높이: 8픽셀
색상:
- 녹색: 보스
- 빨간색: 일반 요괴
애니메이션: 부드러운 감소 (0.3초)
```

**패턴 예고**:
```
위치: 요괴 상단
크기: 40x40 픽셀 아이콘
내용:
- 아이콘: 공격 타입 표시
- 텍스트: "다음 턴: 강공격"
- 카운트다운: "2턴 후"
색상:
- 일반 공격: 회색
- 강공격: 주황색
- 스킬: 빨간색
```

### 2.4 퍼즐 보드

**보드 크기**:
```
화면 너비의 95% (양쪽 여백 2.5%)
정사각형 비율 유지
조각 크기: 자동 계산 (보드 크기 ÷ 7)
간격: 조각 크기의 5%
```

**조각 디자인**:
```
기본 크기: 동적 (화면 대응)
테두리: 2픽셀 (선택 시 4픽셀)
그림자: 2픽셀 오프셋 (깊이감)

상태별 표시:
- 기본: 100% 불투명도
- 선택: 테두리 강조 + 120% 크기
- 매치 대기: 흰색 테두리 + 펄스 효과
- 제거 중: 페이드아웃 + 축소 (0.3초)
```

**드래그 경로 표시**:
```
라인:
- 두께: 6픽셀
- 색상: 속성별 색상
- 불투명도: 70%
- 연결: 조각 중심점 연결

선택된 조각:
- 크기: 110%
- 테두리: 흰색 굵게
- 순서 번호 표시 (1, 2, 3...)
```

### 2.5 캐릭터 바

**캐릭터 슬롯**:
```
개수: 4개 (리더 1 + 서브 3)
크기: 60x60 픽셀
간격: 10픽셀

표시 요소:
- 캐릭터 아이콘
- 속성 표시 (좌측 상단 작은 아이콘)
- 등급 표시 (별 개수)
- HP 바 (하단, 5픽셀 높이)
```

**스킬 버튼**:
```
크기: 캐릭터 슬롯과 동일 (60x60)
위치: 각 캐릭터 하단

상태:
- 비활성: 회색 + 게이지 % 표시
- 활성: 속성 색상 + 반짝임 효과
- 쿨타임: 어두움 + 남은 턴 표시
```

**기능 버튼**:
```
설정 버튼 (⚙️):
- 크기: 50x50 픽셀
- 위치: 우측 하단
- 기능: 옵션 메뉴

일시정지 버튼 (❚❚):
- 크기: 50x50 픽셀
- 위치: 설정 버튼 좌측
- 기능: 전투 일시정지
```

## 3. 피드백 시스템

### 3.1 시각 피드백

**매치 성공**:
```
조각 제거:
- 애니메이션: 축소 + 회전 (0.3초)
- 파티클: 속성별 색상 파티클 (10~15개)
- 플래시: 짧은 흰색 번쩍임

연쇄 발생:
- 텍스트: "CHAIN!" + 연쇄 수
- 크기: 연쇄 수에 비례 (최대 2배)
- 색상: 연쇄 수별 그라데이션
  · 1~2: 하얀색
  · 3~4: 노란색
  · 5+: 황금색
```

**데미지 표시**:
```
숫자 팝업:
- 크기: 기본 40pt (크리티컬 60pt)
- 색상: 속성별 색상
- 애니메이션:
  1. 작은 크기로 나타남 (0.1초)
  2. 크게 확대 (0.2초)
  3. 위로 떠오르며 페이드아웃 (0.5초)

크리티컬:
- 추가 효과: 별 파티클
- 텍스트: "CRITICAL!" (빨간색)
- 화면 플래시
```

**콤보 피드백**:
```
10 콤보:
- 텍스트: "Good!" (녹색)
- 효과: 작은 화면 흔들림
- 사운드: 긍정 효과음

20 콤보:
- 텍스트: "Great!" (파란색)
- 효과: 중간 화면 흔들림
- 사운드: 더 큰 효과음

30 콤보 이상:
- 텍스트: "Excellent!" (황금색)
- 효과: 큰 화면 흔들림 + 화면 번쩍임
- 파티클: 황금 별 파티클
- 사운드: 강렬한 효과음
```

**스킬 발동**:
```
연출 순서:
1. 화면 정지 (0.1초)
2. 캐릭터 컷인 등장 (0.5초)
3. 스킬 이름 표시 (0.3초)
4. 스킬 효과 발동 (0.7~2초)
5. 데미지/효과 적용 (0.3초)

화면 효과:
- 배경 블러 처리
- 캐릭터 강조 라이팅
- 속성별 색상 오버레이
- 화면 플래시
```

### 3.2 음향 피드백

**UI 사운드**:
```
버튼 클릭: 짧은 딸깍 소리 (0.05초)
매치 성공: 경쾌한 종소리 (0.2초)
연쇄: 음계가 높아지는 소리 (연쇄당 반음씩 상승)
```

**전투 사운드**:
```
일반 공격: 타격음 (0.1초)
크리티컬: 강렬한 타격음 (0.15초)
스킬 발동: 전용 효과음 (0.3~1초)
적 사망: 폭발음 (0.5초)
```

**캐릭터 보이스**:
```
스킬 사용:
- ★★★: 효과음만
- ★★★★: 스킬 대사
- ★★★★★: 스킬 대사 + 추가 대사

보이스 타이밍:
- 발동: "스킬 이름!"
- 히트: "맞았어!"
- 승리: "해냈다!"
```

### 3.3 촉각 피드백 (햅틱)

**진동 패턴**:
```
매치 성공: 짧은 진동 (50ms)
크리티컬: 2회 진동 (100ms, 50ms)
스킬 발동: 긴 진동 (200ms)
적 격파: 3회 진동 (100ms, 100ms, 100ms)
```

**설정 옵션**:
```
진동 강도:
- OFF: 진동 없음
- 약함: 50% 강도
- 보통: 100% 강도 (기본)
- 강함: 150% 강도
```

## 4. 접근성 설계

### 4.1 색맹 지원

**색맹 모드**:
```
옵션:
- 일반 (기본)
- 적록 색맹 모드
- 청황 색맹 모드

적용:
- 조각에 패턴 추가

  · 수: 점무늬

  · 금: 격자무늬

- 아이콘 강조
```

### 4.2 저시력 지원

**큰 글자 모드**:
```
텍스트 크기: 120%
UI 요소 크기: 110%
간격 증가: 15%
```

**고대비 모드**:
```
배경: 검은색
텍스트: 흰색
버튼: 높은 대비 색상
테두리: 두껍게
```

### 4.3 조작 보조

**원핸드 모드**:
```
UI 배치: 하단 집중
중요 버튼: 엄지 도달 범위
드래그 거리: 짧게 조정
```

**자동 전투**:
```
활성화: 설정에서 켜기
동작: AI가 자동으로 매치
속도: 2배속 (설정 가능)
```

## 5. 반응형 디자인

### 5.1 화면 크기 대응

**해상도별 레이아웃**:
```
소형 (< 5인치):
- UI 요소 축소 (90%)
- 글자 크기 유지
- 간격 축소

중형 (5~6인치):
- 기본 레이아웃 (100%)

대형 (6인치 이상):
- UI 요소 확대 (110%)
- 여백 증가
```

### 5.2 종횡비 대응

**16:9 (표준)**:
```
기본 레이아웃 적용
```

**18:9, 19:9, 20:9 (길쭉한 화면)**:
```
보드: 중앙 고정
상단/하단: 여백 증가
캐릭터 바: 하단 고정
```

**4:3 (구형)**:
```
보드: 약간 축소 (95%)
UI: 좌우 여백 축소
```

## 6. 성능 최적화

### 6.1 렌더링 최적화

**프레임 타겟**:
```
목표: 60 FPS
최소: 30 FPS

  · SSR: 보라색 빛 + 별
  · UR: 금색 빛 + 화려한 별

4단계 (2초):
- 캐릭터 일러스트 표시
- 이름, 등급, 속성 표시
- 스킬 간략 소개
- "터치로 계속" 버튼
```

**10+1 뽑기 연출**:
```
1단계 (0.5초):
- 화면 전환
- 배경: 화려한 공간

2단계 (2초):
- 11장의 카드 등장
- 웨이브 형태로 배치
- 좌→우 순차 등장

3단계:
- 카드 자동 뒤집기
- 0.2초 간격으로 순차
- 등급 높은 것부터 표시

4단계 (3초):
- 결과 요약 화면
- 등급별 개수 표시
- 신규 획득 강조
- "확인" 버튼
```

### 9.6 최근 획득 목록

**목록 표시**:
```
슬롯: 8개 (가로 스크롤)
크기: 각 120x120 픽셀

표시:
- 캐릭터 아이콘
- 등급 (별)
- 신규: NEW 배지 (빨간색)
- 중복: 조각 개수

터치:
- 상세 정보 팝업
- 캐릭터 화면으로 이동
```

### 9.7 하단 메뉴

**확률 정보**:
```
팝업 내용:
- 등급별 확률 테이블
- 픽업 캐릭터 개별 확률
- 천장 시스템 설명
- 법적 공지사항
```

**뽑기 이력**:
```
목록 표시:
- 최근 100회 기록
- 날짜/시간
- 획득 캐릭터
- 등급 필터
- CSV 내보내기 기능
```

**교환소**:
```
기능: 중복 조각 → 선택권
환율:
- R: 1조각 = 1포인트
- SR: 1조각 = 5포인트
- SSR: 1조각 = 20포인트
- UR: 1조각 = 100포인트

상품:
- 선택 소환권
- 강화 재료
- 한정 아이템
```
