## 1. 시스템 개요

### 1.1 기획 의도

> **💭 왜 이 시스템을 만드는가?**
>
> 전통적인 턴제 RPG의 느린 템포와 단순 매치-3 퍼즐의 단조로움을 극복하기 위해, **전략적 깊이**와 **빠른 액션**을 동시에 제공하는 하이브리드 전투 시스템을 설계했습니다.
>
> **핵심 목표**:
> - ⚡ **즉각적인 피드백**: 매치 → 데미지 → 연쇄의 빠른 순환으로 만족감 제공
> - 🎯 **전략적 선택**: 속성 상성, 스킬 타이밍, 콤보 연계 등 다층적 의사결정
> - 🎮 **쉬운 진입장벽**: 드래그만으로 플레이 가능한 직관적 조작
> - 🏆 **높은 숙련도 차이**: 연쇄와 콤보로 고수와 초보의 명확한 차이 구현
>
> **차별화 포인트**:
> - 기존 매치-3: 인접한 2개만 교환 → **본 시스템**: 경로를 그려 3개 이상 자유롭게 연결
> - 일반 퍼즐 RPG: 속성이 데미지만 영향 → **본 시스템**: 속성 상성(1.5배/0.5배) + 스킬 게이지 충전(2배)으로 전략 깊이 강화

### 1.2 시스템 목적
- 게임의 핵심 전투 메커니즘 제공
- 퍼즐과 RPG 요소의 융합
- 전략적 사고와 빠른 판단력 요구
- 직관적이면서도 깊이 있는 게임플레이

### 1.3 핵심 컨셉
**"속성 조각을 연결하여 요괴를 퇴치하는 퍼즐 배틀"**

## 2. 퍼즐 보드 시스템

### 2.1 보드 구성
**보드 크기**: 7x7 (총 49칸)
- 가로 7칸 × 세로 7칸
- 정사각형 그리드 형태
- 각 칸에 속성 조각 배치

**초기 보드 생성 규칙**:
- 게임 시작 시 랜덤 조각 배치
- 단, 초기 상태에서 3매치가 만들어지지 않도록 보장
- 최소 1회 이상의 매치 가능 상태 보장

**보드 생성 알고리즘**:
```
1. 49칸에 5가지 속성 조각을 랜덤 배치
2. 가로/세로로 3개 이상 연속된 조각 검사
3. 연속 발견 시 해당 조각을 다른 속성으로 교체
4. 2-3번 반복 (최대 10회 시도)
5. 매치 가능 상태 검증 (Flood Fill 알고리즘)
6. 매치 불가능 시 전체 재생성
```

**보드 리필 시스템**:
- 매치로 조각 제거 시 상단에서 새 조각 낙하
- 낙하 속도: 0.2초/칸
- 낙하 애니메이션: Ease-Out 곡선
- 빈 공간이 모두 채워질 때까지 반복

### 2.2 조각 종류

#### 기본 속성 조각
| 속성 | 색상 | 아이콘 | 효과 |
|------|------|--------|------|
| 화(火) | 빨강 | 불꽃 | 화속성 데미지 |
| 수(水) | 파랑 | 물방울 | 수속성 데미지 |
| 목(木) | 초록 | 나뭇잎 | 목속성 데미지 |
| 금(金) | 노랑 | 번개 | 금속성 데미지 |
| 토(土) | 갈색 | 바위 | 토속성 데미지 |

#### 특수 조각
**폭탄 조각** (4개 매치 시 생성):
- 외형: 해당 속성 + 폭탄 아이콘
- 효과: 터뜨리면 주변 3x3 범위(9칸) 제거
- 데미지: 일반 매치의 1.5배

**레이저 조각** (5개 일직선 매치 시 생성):
- 외형: 해당 속성 + 화살표 아이콘
- 효과: 가로 또는 세로 한 줄 전체 제거
- 데미지: 일반 매치의 2배

**레인보우 조각** (L자/T자 매치 시 생성):
- 외형: 무지개 색상
- 효과: 모든 속성과 매치 가능
- 사용 시: 선택한 조각의 속성으로 변환되어 매치

**조각 생성 우선순위**:
1. 레인보우 조각 (L자, T자 매치)
2. 레이저 조각 (5개 일직선)
3. 폭탄 조각 (4개 매치)

## 3. 매치 메커니즘

### 3.1 기본 매치 규칙
**3-매치 기본 규칙**:
- 같은 속성 조각 3개 이상을 인접하게 연결
- 가로, 세로, 대각선 불가 (가로/세로만 가능)
- 연결된 조각들이 동시에 제거되며 데미지 발생

**조작 방식**:
```
방법 1: 스와이프 (권장)
- 조각을 드래그하여 경로 그리기
- 손가락을 떼면 매치 실행
- 최소 거리: 30픽셀 이동
- 드래그 중 경로 하이라이트 표시

방법 2: 터치
- 조각을 순서대로 터치하여 선택
- 3개 이상 선택 시 자동 매치
- 터치 반경: 조각 중심 기준 ±20픽셀
```

**매치 유효성 검증**:
```
검증 조건:
1. 인접성 검사: 각 조각이 이전 조각과 상하좌우로 인접
2. 중복 검사: 같은 조각을 2번 선택하지 않음
3. 속성 일치: 모든 선택된 조각의 속성이 동일
4. 최소 개수: 3개 이상 선택
5. 경로 검증: 교차하거나 되돌아가지 않음

실패 시 처리:
- 시각 피드백: 빨간색 깜빡임
- 음향 피드백: 에러 사운드
- 선택 초기화
```

### 3.2 매치 시 데미지 계산

> **💡 기본 공식**
> ```
> 기본 데미지 = 캐릭터 공격력 × 속성 계수 × 매치 개수 보정
> ```

**매치 개수별 보정**

| 매치 개수 | 데미지 배율 |
|-----------|-------------|
| 3개 | 1.0배 (기본) |
| 4개 | 1.3배 |
| 5개 | 1.6배 |
| 6개 | 2.0배 |
| 7개 이상 | 2.5배 |

**속성 상성 계수**

| 상성 | 데미지 배율 | 설명 |
|------|-------------|------|
| 유리 | 1.5배 | 상성 우위 |
| 보통 | 1.0배 | 상성 없음 |
| 불리 | 0.5배 | 상성 열세 |

> 📊 상세한 속성 상성표는 [[../03_데이터/element_chart.csv|element_chart.csv]] 참고

### 3.3 연쇄 (Cascade) 시스템
**연쇄 발생 조건**:
1. 매치로 조각 제거
2. 상단에서 새 조각 낙하
3. 낙하한 조각이 자동으로 매치 형성
4. 추가 데미지 발생

**연쇄 보너스**:
```
연쇄 데미지 = 기본 데미지 × 연쇄 배율

연쇄 배율:
- 1연쇄: 1.0배 (기본)
- 2연쇄: 1.2배
- 3연쇄: 1.5배
- 4연쇄: 1.8배
- 5연쇄 이상: 2.0배 + (연쇄 수 - 5) × 0.1배 (최대 3.0배)
```

### 3.4 콤보 시스템
**콤보 카운트 조건**:
- 연속으로 매치 성공 시 콤보 증가
- 3초 이내에 다음 매치를 해야 콤보 유지
- 실패하거나 3초 경과 시 콤보 초기화

**콤보 효과**:
```
콤보 보너스 = 기본 데미지 × (1 + 콤보 수 × 0.05)

예시:
- 10 콤보: 1.5배
- 20 콤보: 2.0배
- 30 콤보: 2.5배
```

**콤보 시각 피드백**:
- 10 콤보: "Good!" 메시지 + 화면 흔들림(소)
- 20 콤보: "Great!" 메시지 + 화면 흔들림(중)
- 30 콤보: "Excellent!" 메시지 + 화면 흔들림(대) + 특수 이펙트

## 4. 전투 흐름

### 4.1 전투 시작
```
전투 준비 화면
  ↓
파티 편성 확인 (메인 퇴마사 1 + 서브 3)
  ↓
스태미나 소모 (스테이지별 상이)
  ↓
전투 로딩 (배경, 요괴 등장)
  ↓
전투 시작 (보드 초기화)
```

### 4.2 턴 구조
**퍼즐 RPG 특성상 턴제 + 실시간 혼합**:

```
[플레이어 페이즈]
1. 퍼즐 조작 시작 (제한 시간 30초)
2. 매치 실행
3. 데미지 계산 및 적용
4. 연쇄/콤보 처리
5. 스킬 게이지 충전

[요괴 페이즈]
1. 요괴의 행동 패턴 실행
2. 플레이어에게 데미지
3. 상태 이상 적용 (해당 시)
4. 버프/디버프 효과 처리

[턴 종료]
1. 지속 효과 카운트 감소
2. 다음 턴으로 진행
```

**제한 시간**:
- 기본 제한 시간: 30초/턴
- 시간 초과 시: 자동으로 턴 종료, 요괴 공격
- 노말 난이도: 제한 없음 (초보자 친화)

**턴 진행 상세 프로세스**:
```
1. 턴 시작
   - 카운트다운 타이머 시작
   - 보드 활성화
   - 요괴 패턴 예고 갱신

2. 플레이어 입력
   - 드래그/터치 입력 대기
   - 매치 실행 또는 스킬 발동
   - 시간 경과 UI 업데이트

3. 데미지 계산
   - 매치 개수별 배율 적용
   - 속성 상성 계산
   - 연쇄/콤보 보너스 적용
   - 캐릭터 스탯 반영
   - 버프/디버프 효과 계산

4. 피격 판정
   - 요괴 HP 감소 애니메이션
   - 데미지 숫자 팝업
   - 상태 이상 부여 (해당 시)
   - 격파 판정

5. 스킬 게이지 충전
   - 제거한 조각 수 계산
   - 속성 일치 보너스 적용
   - 게이지 UI 업데이트

6. 요괴 행동
   - 패턴에 따른 공격 실행
   - 플레이어 HP 감소
   - 버프/디버프 적용
   - 특수 패턴 실행

7. 턴 종료 처리
   - 지속 효과 카운트 -1
   - 만료된 효과 제거
   - 다음 턴 준비
```

### 4.3 요괴 행동 패턴
**패턴 예고 시스템**:
- 요괴의 다음 행동을 미리 표시
- 아이콘으로 공격 종류 표시 (일반 공격/강공격/스킬 등)
- 카운트다운 표시 (N턴 후 사용)

**행동 패턴 예시**:
```
약한 요괴 (도깨비):
- 턴 1~3: 일반 공격 (데미지 100)
- 턴 4: 강공격 (데미지 300)
- 턴 5~: 반복

강한 요괴 (구미호):
- 턴 1: 일반 공격
- 턴 2: 버프 (공격력 +50%)
- 턴 3: 강공격 (버프 적용 상태)
- 턴 4: 상태 이상 (매혹)
- 턴 5~: 반복
```

## 7. 전투 종료

### 7.1 승리 조건
- 모든 요괴의 HP를 0으로 만들기
- 제한 턴 내 처치 (일부 스테이지)

### 7.2 패배 조건
- 아군 전체 HP가 0이 됨
- 제한 턴 초과 (해당 스테이지만)

### 7.3 보상 획득
**기본 보상**:
- 골드: 스테이지 레벨 × 100
- 경험치: 스테이지 레벨 × 50
- 아이템: 랜덤 드롭 (확률 기반)

**클리어 등급 평가**:
```
평가 기준:
- 남은 턴 수 (또는 클리어 시간)
- 콤보 최고 기록
- 남은 HP 비율

S등급: 3가지 조건 모두 충족 → 보상 2배
A등급: 2가지 조건 충족 → 보상 1.5배
B등급: 1가지 조건 충족 → 보상 1.2배
C등급: 클리어만 → 보상 1.0배
```

## 8. 난이도 조정

### 8.1 난이도별 차이
| 난이도 | 요괴 HP | 요괴 공격력 | 보상 | 제한 |
|--------|---------|-------------|------|------|
| 노말 | 100% | 100% | 100% | 시간 제한 없음 |
| 하드 | 150% | 120% | 150% | 턴 제한 추가 |
| 엘리트 | 200% | 150% | 200% | 특수 패턴 추가 |

### 8.2 스테이지 진행에 따른 난이도 증가
```
요괴 HP = 기본 HP × (1 + 스테이지 레벨 × 0.15)
요괴 공격력 = 기본 공격력 × (1 + 스테이지 레벨 × 0.10)
```
