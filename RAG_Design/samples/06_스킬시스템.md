## 1. 시스템 개요

### 1.1 기획 의도

> **💭 왜 이 시스템을 만드는가?**
>
> 퍼즐 플레이의 **반복성**을 깨고 **극적인 역전**의 순간을 연출하기 위해, 캐릭터별 고유한 필살기 시스템을 설계했습니다.
>
> **핵심 목표**:
> - ⚡ **역전의 카타르시스**: 위기 상황에서 스킬 발동으로 전세 역전
> - 🎭 **캐릭터 개성**: 80+ 캐릭터 × 고유 스킬 = 강력한 차별화 요소
> - 🎯 **전략적 타이밍**: 즉시 쓸지, 아낄지 선택으로 숙련도 차이 발생
> - 🎬 **화려한 연출**: 2~3초 컷인으로 스킬 사용의 쾌감 극대화
>
> **차별화 포인트**:
> - 일반 매치-3: 스킬 없음 → **본 시스템**: 액티브 + 패시브 + 리더 3종 스킬
> - 자동 발동: 충전되면 즉발 → **본 시스템**: 수동 발동으로 타이밍 선택권 부여
> - 단순 데미지: 숫자만 증가 → **본 시스템**: 보드 조작/버프/디버프 등 다양한 효과
>
> **스킬 게이지 설계 철학**:
> ```
> 왜 속성 일치 시 2배 충전?
> → 속성 상성만으로는 파티 구성이 단조로움
> → 같은 속성 매치 유도로 전략적 플레이 장려
> → "유리한 속성으로 빨리 충전해서 역전" 시나리오 유도
>
> 예시:
> 화속성 캐릭터로 화 조각 5개 매치
> → 데미지: 기본 (속성 일치는 데미지 증가 없음)
> → 게이지: +10 (일반 +5 대비 2배)
> → 10턴 만에 스킬 발동 가능
> ```
>
> **연출 우선순위**:
> - ★~★★: 빠른 연출 (1초) - 리듬 유지
> - ★★★★: 중간 연출 (2초) - 만족감
> - ★★★★★: 긴 연출 (3초) + 보이스 - 프리미엄 경험
> - 스킵 옵션: 반복 플레이 시 편의성

### 1.2 시스템 목적
- 전투에서 역전의 기회 제공
- 캐릭터별 개성과 차별화
- 전략적 타이밍 선택 중요성
- 화려한 연출로 만족감 제공

### 1.3 핵심 컨셉
**"적절한 타이밍에 발동하는 강력한 필살기"**

## 2. 스킬 종류

### 2.1 액티브 스킬

**정의**:
- 캐릭터당 1개 보유
- 스킬 게이지 100% 충전 시 수동 발동
- 전투의 핵심 메커니즘

**발동 조건**:
```
스킬 게이지 100% 도달
→ 스킬 버튼 활성화
→ 플레이어가 원하는 타이밍에 수동 발동
→ 발동 후 게이지 0으로 초기화
```

**게이지 충전 메커니즘**:
```
기본 충전량 = 제거한 조각 수 × 속성 일치 보너스

속성 일치 보너스:
- 같은 속성 조각: ×2.0 (2배 충전)
- 다른 속성 조각: ×1.0 (기본)

예시:
- 화속성 캐릭터가 화 조각 5개 매치 → 게이지 +10
- 화속성 캐릭터가 수 조각 5개 매치 → 게이지 +5
```

### 2.2 패시브 스킬

**정의**:
- 전투 중 항상 발동되는 능력
- 캐릭터당 최대 3개 보유
- 돌파를 통해 해금

**해금 조건**:
```
기본: 패시브 1개 (초기 보유)
2차 돌파 (Lv.50): 패시브 2개 해금
3차 돌파 (Lv.70): 패시브 3개 해금
```

**발동 방식**:
```
상시형: 항상 적용 (예: HP +20%)
조건형: 특정 조건 충족 시 발동 (예: HP 50% 이하일 때 방어력 +30%)
확률형: 일정 확률로 발동 (예: 공격 시 30% 확률로 추가 타격)
```

### 2.3 리더 스킬

**정의**:
- 파티 리더로 설정 시에만 발동
- 파티 전체에 영향
- 파티 편성의 핵심 요소

**효과 범위**:
```
파티 전체 버프:
- 특정 속성 캐릭터 강화
- 특정 직업 캐릭터 강화
- 전체 스탯 상승

예시:
- "화속성 캐릭터 공격력 +30%"
- "검사 직업 크리티컬 확률 +15%"
- "파티 전체 HP +20%"
```

## 3. 스킬 타입별 분류

### 3.1 공격형 스킬

**단일 대상 고화력**:
```
효과: 요괴 1마리에게 강력한 데미지
데미지 배율: 300~500%
쿨타임: 게이지 충전 필요
재사용: 게이지 100% 충전 후

예시:
- "퇴마검술": 적 단일에게 공격력 400%의 화속성 데미지
- "일섬": 적 단일에게 공격력 500%의 금속성 데미지 + 즉사 5%
```

**범위 공격**:
```
효과: 모든 요괴에게 데미지
데미지 배율: 150~250% (분산)
대상 수: 전체
효율: 다수 적 상대 시 유리

예시:
- "부적 난무": 적 전체에게 공격력 200%의 목속성 데미지
- "화염 폭발": 적 전체에게 공격력 180%의 화속성 데미지 + 화상
```

**연속 공격**:
```
효과: 여러 번 공격
횟수: 2~5회
총 데미지: 300~400%
특징: 콤보 연출

예시:
- "연참": 적 단일을 5번 공격, 총 350% 데미지
- "난격": 적 랜덤 대상을 4번 공격, 총 320% 데미지
```

### 3.2 보드 조작형 스킬

**속성 변환**:
```
효과: 특정 속성 조각을 다른 속성으로 변환
개수: 5~20개
용도: 매치 준비, 연쇄 유도

예시:
- "화염 인술": 토 조각 10개를 화 조각으로 변환
- "수류탄": 랜덤 조각 15개를 수 조각으로 변환
```

**보드 셔플**:
```
효과: 전체 보드를 재배치
특수: 매치 가능한 상태 보장
용도: 막힌 상황 타개

예시:
- "혼돈의 부적": 보드 전체를 재배치 + 폭탄 조각 2개 생성
```

**특수 조각 생성**:
```
효과: 폭탄/레이저/레인보우 조각 생성
개수: 2~4개
배치: 랜덤 또는 지정 위치

예시:
- "번개 소환": 레이저 조각 3개를 랜덤 위치에 생성
- "대지의 분노": 폭탄 조각 4개를 모서리에 생성
```

### 3.3 서포트형 스킬

**회복**:
```
효과: 아군 HP 회복
회복량: 최대 HP의 20~40%
대상: 단일 or 전체

예시:
- "회생술": 아군 전체 HP 30% 회복
- "대회복": 아군 전체 HP 40% 회복 + 재생 3턴
```

**버프**:
```
효과: 아군 능력치 증가
지속: 3~5턴
종류: 공격력, 방어력, 속도, 크리티컬

예시:
- "투지 고취": 3턴간 아군 전체 공격력 +40%
- "철벽 방진": 5턴간 아군 전체 방어력 +50%
```

**디버프**:
```
효과: 적 능력치 감소
지속: 2~3턴
종류: 공격력, 방어력, 속도, 명중률

예시:
- "약화의 부적": 3턴간 적 전체 공격력 -30%
- "둔화의 저주": 2턴간 적 전체 속도 -40%
```

**정화/해제**:
```
효과: 상태 이상 제거
개수: 1~전체
대상: 아군 or 적

예시:
- "정화의 물결": 아군 전체 상태 이상 1개 해제
- "만병통치술": 아군 전체 모든 상태 이상 해제
```

## 4. 스킬 레벨 시스템

### 4.1 레벨 구조

**레벨 범위**:
```
최소: Lv.1 (기본)
최대: Lv.10 (최종)
```

**레벨업 재료**:
```
방법 1: 스킬 북 사용 (공통)
- Lv.1→2: 스킬 북 × 1
- Lv.2→3: 스킬 북 × 2
- ...
- Lv.9→10: 스킬 북 × 9

방법 2: 동일 캐릭터 중복 (100% 성공)
- 중복 캐릭터 1명 = 스킬 레벨 +1

필요 골드:
- Lv.1→2: 10,000 골드
- Lv.5→6: 50,000 골드
- Lv.9→10: 150,000 골드
```

### 4.2 레벨별 효과 증가

**데미지/회복량**:
```
Lv.1 → Lv.10: +100% 증가

예시:
- Lv.1: 공격력 300% 데미지
- Lv.5: 공격력 400% 데미지
- Lv.10: 공격력 600% 데미지

증가량: 레벨당 +10%
```

**지속 시간**:
```
특정 레벨에서 +1턴

Lv.5: 지속 시간 +1턴
Lv.10: 지속 시간 +1턴 (총 +2턴)

예시:
- Lv.1: 버프 3턴 지속
- Lv.5: 버프 4턴 지속
- Lv.10: 버프 5턴 지속
```

**부가 효과**:
```
특정 레벨에서 효과 추가

Lv.7: 부가 효과 1개 추가
Lv.10: 부가 효과 2개 또는 강화

예시:
- Lv.1: 단일 공격 300%
- Lv.7: 단일 공격 450% + 방어력 -20% 3턴
- Lv.10: 단일 공격 600% + 방어력 -30% 3턴 + 출혈
```

## 5. 스킬 연출

### 5.1 시각 연출

**컷인 애니메이션**:
```
등급별 연출 시간:
★~★★: 1초 (간단)
★★★: 1.5초 (보통)
★★★★: 2초 (화려)
★★★★★: 3초 (매우 화려 + 보이스)

구성:
1. 캐릭터 컷인 (0.5초)
2. 스킬 이름 표시 (0.3초)
3. 스킬 효과 발동 (0.7~2.2초)
```

**화면 효과**:
```
공격형:
- 화면 플래시
- 타격 파티클
- 카메라 흔들림

서포트형:
- 빛 번짐 효과
- 힐링 파티클
- 부드러운 전환

보드 조작형:
- 조각 변환 애니메이션
- 연쇄 효과
- 색상 변화
```

### 5.2 음향 연출

**효과음**:
```
스킬 발동: 전용 효과음 (0.2초)
타격음: 등급별 차등 (0.1초)
추가 효과음: 속성별 특수음 (0.3초)
```

**캐릭터 보이스**:
```
★★★★ 이상: 스킬 대사
- 발동 시: "스킬 이름!"
- 히트 시: "맞았다!"
- 피니시: "이걸로 끝이다!"

★★★★★: 추가 대사
- 크리티컬: "회심의 일격!"
- 킬: "처치 완료!"
```

### 5.3 스킵 기능

**스킵 옵션**:
```
설정:
- 스킵 OFF: 전체 연출 재생 (기본)
- 스킵 ON: 즉시 결과만 표시
- 1회 재생: 첫 사용 시만 연출, 이후 스킵

버튼:
- 연출 중 화면 터치 → 즉시 스킵
```

## 6. 스킬 밸런싱

### 6.1 타입별 기준 성능

**공격형 스킬 DPS 기준**:
```
단일 대상: 400% (기준)
범위 공격: 200% × 적 수 (분산)
연속 공격: 350% (총합)

조정 계수:
- 속성 상성 우위: -10%
- 추가 효과 有: -15%
- 쿨타임 짧음: -20%
```

**서포트형 스킬 효율**:
```
회복: 최대 HP의 30% (기준)
버프: +30% 3턴 (기준)
디버프: -25% 3턴 (기준)

조정:
- 전체 대상: -20% 효과
- 단일 대상: +50% 효과
```

### 6.2 밸런스 모니터링 지표

**사용률**:
```
목표: 각 스킬 타입 10~15%
주의: 25% 초과 시 너프 검토
```

**승률 기여도**:
```
승리 시 사용된 스킬 분석
특정 스킬 의존도 측정
```
