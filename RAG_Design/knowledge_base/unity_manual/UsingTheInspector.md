# The Inspector window
The ****Inspector**** window displays the properties of the current selection of one or more GameObjects, assets, or components. You can use the **Inspector** window to view and edit the properties of the selected items.
| Topic | Description |
| --- | --- |
| [Manage the Inspector window](InspectorOptions.html) | Open the **Inspector** window in normal or debug mode. |
| [Inspect items](InspectorItems.html) | Learn what the **Inspector** window displays for GameObjects, prefabs, assets, and **scripts**A piece of code that allows you to create your own Components, trigger game events, modify Component properties over time and respond to user input in any way you like. [More info](creating-scripts.html) See in [Glossary](Glossary.html#Scripts). |
| [Focus an Inspector window](InspectorFocused.html) | Keep the window focused on a single item, regardless of the current selection. |
| [Assign icons to inspected items](InspectorAssignIcons.html) | Assign built-in or custom icons to display on the item in the ****Scene**A Scene contains the environments and menus of your game. Think of each unique Scene file as a unique level. In each Scene, you place your environments, obstacles, and decorations, essentially designing and building your game in pieces. [More info](CreatingScenes.html) See in [Glossary](Glossary.html#Scene) view**. |
| [Manage components and their values](InspectorManageComponents.html) | Edit component properties. |
