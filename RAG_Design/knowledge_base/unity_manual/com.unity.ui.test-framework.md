# UI Test Framework
[com.unity.ui.test-framework](https://docs.unity3d.com/Packages/com.unity.ui.test-framework@1.0/manual/index.html)
## Description
UIToolkit Test framework for running Edit mode and Play mode tests in Unity.
## Version information
Core packages are fixed to a single version matching the Editor version.
