# Rotation over Lifetime module reference
Here, you can configure **particles**A small, simple image or mesh that is emitted by a particle system. A particle system can display and move particles in great numbers to represent a fluid or amorphous entity. The effect of all the particles together creates the impression of the complete entity, such as smoke. [More info](class-ParticleSystem.html)
See in [Glossary](Glossary.html#particle) to rotate as they move.
## Properties
For some properties in this section, you can use different modes to set their value. For information on the modes you can use, refer to [Vary Particle System properties over time](varying-particle-system-properties-over-time.html).
| Property | Function |
| --- | --- |
| **Separate Axes** | Allow rotation to be specified per axis. When this is enabled, the option to set a rotation for each of X, Y and Z is presented. |
| **Angular Velocity** | Rotation velocity in degrees per second. |
