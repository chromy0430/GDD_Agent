# The Editor interface
Understand the key tools and workflows of the Unity Editor. The Unity Editor is the main workspace you use to create, organize, and manage your application.
| **Topic** | **Description** |
| --- | --- |
| **[The Project window](ProjectView.html)** | An overview of the **Project window**A window that shows the contents of your `Assets` folder (Project tab) [More info](ProjectView.html) See in [Glossary](Glossary.html#Projectwindow). |
| **[The Scene view](UsingTheSceneView.html)** | An overview of the **Scene**A Scene contains the environments and menus of your game. Think of each unique Scene file as a unique level. In each Scene, you place your environments, obstacles, and decorations, essentially designing and building your game in pieces. [More info](CreatingScenes.html) See in [Glossary](Glossary.html#Scene) view. |
| **[The Game view](GameView.html)** | An overview of the Game view. |
| **[The Hierarchy window](Hierarchy.html)** | An overview of the Hierarchy window. |
| **[The Inspector window](UsingTheInspector.html)** | An overview of the **Inspector**A Unity window that displays information about the currently selected GameObject, asset or project settings, allowing you to inspect and edit the values. [More info](UsingTheInspector.html) See in [Glossary](Glossary.html#Inspector) window. |
| **[The Toolbar](Toolbar.html)** | An overview of the **Toolbar**A row of buttons and basic controls at the top of the Unity Editor that allows you to interact with the Editor in various ways (e.g. scaling, translation). [More info](Toolbar.html) See in [Glossary](Glossary.html#toolbar). |
| **[The status bar](StatusBar.html)** | An overview of the status bar. |

| **[Additional windows](OtherViews.html)** | An overview of additional windows. |
