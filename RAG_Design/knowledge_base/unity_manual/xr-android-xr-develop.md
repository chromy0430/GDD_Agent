# Develop for Android XR
Understand the packages and resources you can use to develop for Android **XR**An umbrella term encompassing Virtual Reality (VR), Augmented Reality (AR) and Mixed Reality (MR) applications. Devices supporting these forms of interactive applications can be referred to as XR devices. [More info](XR.html)
See in [Glossary](Glossary.html#XR) devices.
Unity supports development for Google’s Android XR. Refer to the following sections to access resources to develop for Android XR devices:
| **Topic** | **Description** |
| --- | --- |
| [Android XR build platform and build profile](xr-android-xr-build-profile.html) | Understand how to configure the Android XR build platform and **build profile**A set of customizable configuration settings to use when creating a build for your target platform. [More info](build-profiles.html) See in [Glossary](Glossary.html#buildprofile). |
| [Packages and templates for Android XR development](xr-android-xr-packages.html) | Learn about the packages and templates you can use to develop for Android XR with Unity. |
