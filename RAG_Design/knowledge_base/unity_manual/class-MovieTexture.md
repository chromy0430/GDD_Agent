# Movie Texture Inspector window reference
[Switch to Scripting](../ScriptReference/MovieTexture.html "Go to MovieTexture page in the Scripting Reference")
The Movie Texture **Inspector**A Unity window that displays information about the currently selected GameObject, asset or project settings, allowing you to inspect and edit the values. [More info](UsingTheInspector.html)
See in [Glossary](Glossary.html#Inspector) is similar to the [Texture](class-TextureImporter.html)An image used when rendering a GameObject, Sprite, or UI element. Textures are often applied to the surface of a mesh to give it visual detail. [More info](class-TextureImporter.html)
