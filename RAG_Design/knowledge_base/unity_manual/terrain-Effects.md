# Change existing height with effects
**Note:** These tools are only available in the [Terrain Tools package](https://docs.unity3d.com/Packages/com.unity.terrain-tools@latest/).
The height effect tools change existing height features.
| Tool | Description |
| --- | --- |
| [Flatten terrain features](terrain-Effects-Flatten.html) | Flatten fine details on the **terrain**The landscape in your scene. A Terrain GameObject adds a large flat plane to your scene and you can use the Terrain’s Inspector window to create a detailed landscape. [More info](terrain-UsingTerrains.html) See in [Glossary](Glossary.html#Terrain) without changing the slope. |
| [Change peak sharpness](terrain-Effects-Sharpen.html) | Sharpen existing peaks and flatten the areas around them. |
| [Add contrast to features](terrain-Effects-Contrast.html) | Raise high areas and lower low areas at the same time. |
