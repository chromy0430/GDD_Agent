# Normal maps
Resources for using **normal map**A type of Bump Map texture that allows you to add surface detail such as bumps, grooves, and scratches to a model which catch the light as if they are represented by real geometry.
See in [Glossary](Glossary.html#normalmap) textures to add surface detail such as bumps, grooves, and scratches that catch the light.
