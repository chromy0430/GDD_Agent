# The toolbar
You can find the **toolbar**A row of buttons and basic controls at the top of the Unity Editor that allows you to interact with the Editor in various ways (e.g. scaling, translation). [More info](Toolbar.html)
See in [Glossary](Glossary.html#toolbar) at the top of the Editor. The toolbar contains controls that you can use to access specific Unity functionalities.
