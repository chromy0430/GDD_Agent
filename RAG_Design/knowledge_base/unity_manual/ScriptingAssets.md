# Scripting with assets
Access different types of assets from your C# code to use or change them as part of your runtime application.
| **Topic** | **Description** |
| --- | --- |
| **[Stream assets directly into a build](StreamingAssets.html)** | Use a `StreamingAssets` folder to make runtime-ready assets available directly to your built application, bypassing the regular project build process. |
| **[Modify source assets from code](ModifyingSourceAssetsThroughScripting.html)** | Make temporary or permanent modifications to source assets from your runtime application code. |
