# Creating a hierarchy of materials
To create a hierarchy of materials that uses property inheritance, use material variants. If you create hundreds of materials, material variants are easier to manage than duplicating materials.

| --- | --- |
| [Material variants](materialvariant-concept.html) | Learn about the benefits and limitations of using material variants to manage materials. |

| [Control material variant properties](materialvariant-properties.html) | Propagate property changes from a parent to its children, or override parent properties. |
