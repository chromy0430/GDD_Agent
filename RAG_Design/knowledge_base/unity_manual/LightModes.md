# Set the Mode of a Light
To assign a **Mode**, select the Light in your **Scene**A Scene contains the environments and menus of your game. Think of each unique Scene file as a unique level. In each Scene, you place your environments, obstacles, and decorations, essentially designing and building your game in pieces. [More info](CreatingScenes.html)
See in [Glossary](Glossary.html#Scene) and, in the [Light Inspector window](class-Light.html), select **Mode**.
