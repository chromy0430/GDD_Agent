# Customize the build pipeline
Unity’s build pipeline transforms your project into Player builds for target platforms. You can customize this process using custom **scripts**A piece of code that allows you to create your own Components, trigger game events, modify Component properties over time and respond to user input in any way you like. [More info](creating-scripts.html)
See in [Glossary](Glossary.html#Scripts), callbacks, and command-line tools to automate builds and integrate with your development workflow.
