# Configuring lights with the Light Explorer
Resources for using the Light Explorer window to check and configure the light components in a **scene**A Scene contains the environments and menus of your game. Think of each unique Scene file as a unique level. In each Scene, you place your environments, obstacles, and decorations, essentially designing and building your game in pieces.
