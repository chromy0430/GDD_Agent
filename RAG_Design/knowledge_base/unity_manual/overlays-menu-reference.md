# Overlays menu reference
Use the overlays menu to choose which overlays to display or hide, and to create and load overlay presests.
You can set the overlays menu to the **toolbar**A row of buttons and basic controls at the top of the Unity Editor that allows you to interact with the Editor in various ways (e.g. scaling, translation). [More info](Toolbar.html)
See in [Glossary](Glossary.html#toolbar) in panel or horizontal layout.
To learn more, refer to [Change the appearance and position of an overlay](overlays-position-and-display.html).
In the overlay menu panel layout you can use the drop-down to choose an overlay preset. To learn more, refer to [Create and manage overlay presets](manage-overlay-configurations.html).
The overlays menu contains the following properties.
