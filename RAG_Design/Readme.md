app.py - (기본 값)

* 기획서 평가 봇
* criteria 폴더 내부에 평가 기준을 정하는 PDF, TXT 파일을 넣어서 사용



Translator.py

* 실시간 음성 번역기 봇
* 사용자 음성(마이크)을 입력받아 지정된 프롬프트에 따라 실시간으로 타겟 언어로 번역 및 음성 출력



\_Admin\_Settings.py

* 시스템 및 RAG 관리 봇
* 로컬 지식 베이스(PDF/TXT/MD)를 읽어들여 Chroma DB 벡터 데이터베이스를 갱신 및 재구축함



\_Agent\_Orchestrator.py

* 통합 지휘 통제실 (Agent Orchestrator)
* 입력된 문서나 영상을 분석하여 가장 적절한 하위 에이전트(비디오 분석, 명세서 작성 등)를 자동 배정하고 작업을 조율함



\_Balance\_Calc.py

* 게임 밸런스 시뮬레이터
* 몬스터/아이템 데이터 테이블(CSV/Excel)을 첨부하고 시나리오를 입력하면 TTK, DPS 등 전투 결과를 수학적으로 시뮬레이션함



\_Code\_Reviewer.py

* 코드 리뷰 봇
* 특정 코드를 제시하면 검토 후 어떤 부분이 잘못된 것인지 알려주고, Unity 최신 스펙에 맞춰 리팩토링을 해줌



\_Feature\_Implementer.py

* 기능 구현 및 리팩토링 봇
* 신규 기능 구현 코드를 짜주거나, 다수의 레거시 Unity 코드를 업로드하면 Unity 6 최신 문법으로 일괄 리팩토링함



\_GDD\_Writer.py

* 기획서 작성 및 업데이트 봇
* 추상적 아이디어 구상이나 기존 기획서(PDF 등)를 제시하면, 표준 양식에 맞춘 마크다운 기획서를 새로 작성하거나 업데이트해줌



\_Graphics\_Expert.py

* 그래픽스 테크니컬 아티스트 봇
* URP, 쉐이더, 포스트 프로세싱 등 그래픽스와 렌더링 최적화에 대한 기술적 질문에 답변함



\_Market\_Analyst.py

* 시장 분석 봇
* 특정 검색어를 입력하여 그 키워드에 맞추어 게임 시장을 분석해서 결과를 알려줌



\_Reference\_Finder.py

* 레퍼런스 검색 봇
* 특정 검색어를 입력하여 그 키워드에 걸맞는 게임을 찾아줌



\_Spec\_Generator.py

* 개발 명세서 생성 봇
* 특정 시스템 기획서를 제시하면 거기에 맞는 TO-DO 목록과 클래스 구조를 뽑아줌



\_Video\_Analyst.py

* 게임 영상 분석 봇
* 게임플레이 영상을 업로드하면 프레임 단위로 로직을 역설계(Reverse Engineering)하여 기술 명세서를 작성해줌
