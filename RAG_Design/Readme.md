app.py - (기본 값) 

* 기획서 평가 봇
* criteria 폴더 내부에 평가 기준을 정하는 PDF, TXT 파일을 넣어서 사용



\_Spec\_Generator.py

* 개발 명세서 생성 봇
* 특정 시스템 기획서를 제시하면 거기에 맞는 TO-DO 목록과 클래스 구조를 뽑아줌



\_Code\_Reviewer.py

* 코드 리뷰 봇
* 특정 코드를 제시하면 검토 후 어떤 부분이 잘못된 것인지 알려주고, 리팩토링을 해줌



\_Reference\_Finder.py

* 레퍼런스 검색 봇
* 특정 검색어를 입력하여 그 키워드에 걸맞는 게임을 찾아줌



\_Market\_Analyst.py

* 시장 분석 봇
* 특정 검색어를 입력항ㅕ 그 키워드에 맞추어 게임 시장을 분석해서 결과를 알려줌
